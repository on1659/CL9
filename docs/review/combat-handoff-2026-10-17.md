# 인계 — 전투·조작감 개선 (2026-10-17, 분석 끝 → 다음 세션은 결정과 구현)

이 문서는 2026-10-17 세션(분석만 했고 코드·에셋은 건드리지 않았다)이 다음 세션에 넘기는 것이다. 맨 아래에 새 세션을 여는 프롬프트가 있다.

## 1. 사용자가 말한 문제 (원문 요지)

1. "전투가 밍밍하다. 리썰이나 리포에 비해 뭐가 부족한지."
2. "몬스터가 너무 멍청해서 잡는 맛이 안 나고, 무섭지 않고, 깜짝 놀라지 않는다. 깜짝 놀랄 요소가 여기저기 있어야 한다."
3. "9월에 끝났다고 하지만 조작감이 별로다. 타격, 움직임, 그리고 손전등을 켠 채 다른 걸 집으면 꺼지고 다시 켜야 하는 불편까지 다 조작감이다."
4. "아이템을 주우면 손에 든 것이 손전등에서 그 아이템으로 바뀌는 것도 문제다."
5. (질문) "때리거나 움직이거나 겁먹는 건 표현돼야 하나?" → 그렇다. 1인칭이라 카메라·손·소리·화면 네 채널뿐이다. 때리기·움직임은 표현이 있으나 손으로 검증한 적 없고, **겁먹는 표현은 아예 없다.**

## 4. 권하는 순서 (결정이 나온 뒤)

1. **G 손전등 둘** — 가장 자주 느끼는 마찰, 작은 수정.
2. **H 겁먹는 표현** — 비어 있는 자리. 값은 전부 `CL9Rules`/`SoundTable` 행으로(하드코딩 금지).
3. **C 타격 소음 + D 감지 값** — 셀·행만.
4. **B·A·E·F** — 결정의 무게가 큰 것들. 각각 goal 문서를 먼저 쓴다(`/autogoal` 또는 `/goaldoc`).
5. 눈으로 볼 변경은 매번 `/cl9film` 촬영해서 올린다 — 플레이 부탁 대신.

## 5. 별건 — 추가 분석 게임

사용자가 **Content Warning**(놀람·공포)과 **Valheim**(전투 결정) 설치 예정. 둘 다 Mono 라 기존 파이프라인(`Tools/UnityAnalysis`, MCP `unity-analysis`) 그대로.
설치되면 `Tools/UnityAnalysis/games.csv` 에 행 추가 → `inspect_game` → `decompile`. 질문 목록은 아래.

- Content Warning: 몬스터별 감지·등장·사라짐·공격이 HP 인가 통제권 상실인가, 점프스케어 연출(카메라·시선·입력·소리)의 조건, 공포가 보상인 구조(촬영 점수가 무엇을 세나), 소음 모델, 무기·도구가 몬스터에게 하는 일.
- Valheim: 공격 체인·스태미나 소모·넉백·스태거 게이지, 막기·패리 창과 배율, 적 피격 반응·HP 바·도망 조건, 감지(시야·소음·잠복), 무기 역할·내성, 드롭.
