# 옵션 (플레이어 설정) — 기획

> 플레이어가 자기 머신에서 바꾸는 것들. **무엇을 옵션으로 열고 무엇을 열지 않는가**를 이 문서가
> 정하고, UE에서 어떻게 저장·적용·표시하는지는 [../systems/settings.md](../systems/settings.md)가 정한다.
> 기능을 하나 만들 때마다 아래 "옵션으로 열 것인가" 체크리스트를 한 번 돌린다 (2026-09-12 사용자 —
> "옵션 시스템인데 plan이랑 system에도 있어야지, 그래서 어떤 기능 개발할 때 옵션을 넣을지 말지 고민해야 돼").

## 원칙

1. **게임플레이 값은 옵션이 아니다.** 난이도·밸런스·시야 이득이 되는 것(밝기 이득, 몬스터 감지 표시,
   달리기 소모…)은 열지 않는다. 난이도는 일자 곡선이 만들고 어둠은 게임의 일부다
   ([data/rules.md](data/rules.md) · [economy.md](economy.md)).
2. **옵션은 전부 로컬이다.** 각자 머신의 값이고 복제되지 않는다. 판 진행·공유 자금과 섞이지 않는다
   ([../systems/save.md](../systems/save.md)).
3. **바꾸면 그 자리에서 보인다.** 미리보기·재시작 안내 없이 즉시 적용되고, 바꾼 순간 저장된다 —
   어떤 경로로 화면이 닫혀도(밤 시작, 트럭 이동) 잃지 않는다.
4. **옵션이 늘어도 화면은 한 장이다.** 섹션이 늘어날 뿐 새 화면·새 흐름을 만들지 않는다.

## 있는 옵션

| 섹션 | 항목 | 기본 | 비고 |
|---|---|---|---|
| 키 | 모든 게임 동작의 키보드·마우스 키 | IMC 에셋의 기본 키 ([../systems/input.md](../systems/input.md) 키 배치) | 충돌하면 **알리고 맞바꾼다**. 시점(마우스 이동)·게임패드는 대상 아님. [키 초기화] 한 개 |
| 마우스 | 감도 | 100% | 20~300%. 시점 회전 배율일 뿐 조준 이득 없음 |
| 마우스 | Y축 반전 | 끔 | |
| 오디오 | 전체 · 효과음 · UI · 배경음 · 음악 · 음성 | 전부 100% | 믹스 밸런스(효과음 0.8 등)는 사운드 클래스가 갖고, 슬라이더는 그 위에 곱해진다 — 80%로 보이는 기본값은 플레이어가 100%로 "고치게" 만든다 |
| 언어 | 한국어 / English | OS 언어, 없으면 한국어 | 선택지 이름은 그 언어의 원어명 — 잘못 바꾼 사람이 자기 언어를 읽을 수 있어야 한다 |

없는 것(아직): 그래픽(해상도·창 모드·품질), 자막, UI 배율 — 섹션을 붙일 자리는 있다.

## 옵션으로 열 것인가 — 체크리스트

기능을 설계할 때 다음을 순서대로 묻는다. 하나라도 "아니오"면 옵션이 아니다.

1. **이 값이 달라도 판이 공평한가?** 같은 방에 있는 넷이 서로 다른 값을 가져도 유불리가 없어야 한다.
   (감도 ○ · 밝기 ✕ · 몬스터 소리 크기 ✕ — 효과음 전체는 ○이지만 "몬스터만" 따로는 ✕)
2. **플레이어마다 정답이 다른가?** 사람마다 다른 손·귀·눈·언어의 문제인가, 아니면 우리가 정해야 할
   기획값인가. 기획값이면 옵션이 아니라 데이터 표다 ([data/README.md](data/README.md)).
3. **즉시 적용되는가?** 재시작·재접속이 필요한 값은 옵션 화면에 두지 않는다 (그런 값은 아직 없다).
4. **문구·키 표기가 옵션을 따라가는가?** 키를 바꾸면 프롬프트의 `[E]`가 따라 바뀌고, 언어를 바꾸면
   전부 바뀐다 — 옵션에 의존하는 표시는 값을 박지 않고 서식(`{0}`)으로 둔다
   ([../systems/localization.md](../systems/localization.md)).

통과하면 [../systems/settings.md](../systems/settings.md) "옵션 추가" 절대로 붙인다 — 설정 필드 하나,
화면 행 한 줄, 문구 시트 한 행. 어느 섹션에 들어가는지도 거기서 고른다.
