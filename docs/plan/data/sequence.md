# 연출 시퀀스 — `UCL9SequenceDef`

전이 지점에서 트는 짧은 연출. 트럭 도착 · 정전 · 전멸 · 새벽.

공통 컬럼은 [README.md](README.md) 참조. 재생 메커니즘은
[../../systems/sequence.md](../../systems/sequence.md).

> **현재는 구현하지 않음 — 문서만 사전 작성.** `UCL9SequenceDef` 클래스도 `SequenceTable`
> 애셋도 아직 없다. 표를 실제로 만들 때 이 문서가 명세가 된다 (2026-09-09 확인).

---

## 원칙

- **게임은 멈추지 않는다.** 리슨 서버 협동이라 시퀀스 동안에도 판정은 돈다. 카메라를 뺏는
  연출은 몇 초 안으로 짧게 끝낸다.
- **원정 한복판에 긴 컷씬을 넣지 않는다.** 연출 자리는 전이 지점(밤 시작·정전·전멸·새벽)뿐이다.
- **스킵은 로컬이다.** 각자 자기 화면에서 건너뛴다 — 재생은 판정과 무관해서 동기화가 안 깨진다.
- 시퀀스가 끝나야 넘어가는 전이(예: 밤 시작 뒤 조작 개방)는 **호스트가 시퀀스 길이만큼
  타이머로 기다린다** — 클라의 "재생 끝났다" 보고에 의존하지 않는다.

## 컬럼

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| `Alias` | `FName` | `night_start` · `blackout` … |
| `Sequence` | 소프트 참조 | Level Sequence 에셋 (`TSoftObjectPtr<ULevelSequence>`) |
| `bLockLocalInput` | bool | 재생 중 로컬 입력을 잠그나 |
| `bSkippable` | bool | 로컬 스킵 허용 |
| `bHostWaits` | bool | 호스트가 이 시퀀스 길이만큼 전이를 기다리나 |
| `Gimmicks` | Instanced | 이 연출에만 있는 특수 동작 |

## 지금 있는 것

없다. 아래는 초안이다.

| Alias | 언제 | 비고 |
|---|---|---|
| `night_start` | **탈것(트럭)을 타고 시작 지점으로 입장** — 밤 시작 | 짧게. `bHostWaits` — 끝나야 조작 개방. 연출 제작은 후순위 — 그 전엔 스폰 지점에서 바로 시작 |
| `blackout` | 정전 발동 순간 | 카메라를 뺏지 않는다 — 월드 조명 연출 위주 |
| `wipe` | 전멸 — 트럭이 일행을 두고 떠난다 | |
| `dawn` | 새벽 전환 — 정산 화면으로 | |
