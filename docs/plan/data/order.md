# 주문서 — `UCL9OrderDef`

오늘 만들어 팔아야 하는 것. **이 루프의 엔진이다.**

---

## 왜 무게가 아니라 레시피인가

무게제면 "제일 무거운 걸 많이 주워온다"가 언제나 정답이라서 목적지를 고를 이유도 요리할 이유도
없어진다. **주문이 필요한 재료를 정하고, 재료가 목적지를 정한다.**

---

## 컬럼

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| `Alias` | `FName` | `omelette` · `honey_butter` … |
| `DisplayName` | `FText` | 주문서에 뜨는 이름 |
| `Icon` | 소프트 참조 | 주문서 아이콘 |
| `Ingredients` | `TArray<FCL9ItemCount>` | `{ ItemAlias, ItemSubAlias, Count }` — **필요한 완성물** (`egg`+`cooked` 지정에 SubAlias 필요) |
| `RewardMin` / `RewardMax` | int | 보상 (이더) |
| `DeadlineDays` | int | 며칠 안에 (1 = 오늘) |
| `FailPenaltyRate` | float | 마감을 놓치면 보상의 몇 배를 위약금으로 빼나 (초안 0.3) |
| `MinDay` / `MaxDay` | int | 등장 일차 범위 |
| `Weight` | float | 뽑힐 가중치 |
| `Gimmicks` | Instanced | 이 주문에만 있는 조건 |

---

## 재료가 목적지를 정한다

```
주문: 오믈렛 3          →  필요: 익은 계란 3
                        →  익은 계란은 계란을 12초 익혀서 나온다  (item/egg.md)
                        →  계란은 양계장에서 나온다               (site.md)
                        →  오늘은 양계장으로 간다
```

**주문은 완성물(`egg+cooked` 같은)을 요구한다** — 생재료 주문이 없어서 모든 주문이 요리를
거치고, 요리가 장식이 되지 않는다 (현재 설계).

---

## 몇 개 제시하고 몇 개 고르나

이 값은 주문서마다가 아니라 [progression.md](progression.md)에 있다.

| | 뜻 | 초안 |
|---|---|---|
| `OrdersOfferedPerDay` | 하루에 제시하는 개수 N | 3 |
| `OrdersRequiredPerDay` | 골라야 하는 개수 M | 2 |

**N = M이면 선택이 사라진다.** M이 너무 작으면 쉬운 것만 골라 밤이 늘어진다.

---

## 마감

`DeadlineDays`가 1이면 오늘 안에 내야 한다. 2 이상이면 며칠에 걸친 주문이 된다.

**마감을 놓치면 보상의 `FailPenaltyRate`만큼 누적 이더에서 뺀다.** 벌지 못한 만큼은 정산
압박이 이미 벌한다 — 위약금은 그 위에 얹히는 대가다.

**여러 날에 걸친 시간 압박은 납품 마감이다.** 밤 안의 압박은 밤·정전 시계가 담당한다.

---

## 등장 조건

`MinDay` / `MaxDay` / `Weight`로 매일 후보를 뽑는다.

- 초반에는 재료 하나짜리 단순한 주문만 나온다
- 일차가 오르면 재료가 여럿인 주문이 섞인다
- `MaxDay`를 두면 초반 전용 주문을 만들 수 있다

**일자별 목표액은 여기가 아니라 [progression.md](progression.md)의 곡선에 있다.**
주문서는 "무엇을"이고 곡선은 "얼마나"다.

## 지금 있는 것

없다. 아래는 초안이다.

| Alias | 재료 | 보상 (이더) | 비고 |
|---|---|---|---|
| `omelette` | 익은 계란 × 3 | 1050~1350 (초안) | 계란만 있으면 되는 입문 주문 |
| `fried_egg` | 익은 계란 × 1 | 350~450 (초안) | 1일차용 |
| `meat_dish` | 익은 고기 × 2 | 1150~1400 (초안) | 고기 쪽 |
| `honey_butter` | 꿀 × 2, 버터 × 1 | 미정 | **벌집이 생겨야 성립한다** |

**`honey_butter`는 지금 못 만든다** — 꿀이 나오는 목적지가 없다. 목적지가 하나뿐인 동안은
"목적지 선택"이 성립하지 않으므로, 이 층의 재미는 두 번째 목적지가 생겨야 나온다.
