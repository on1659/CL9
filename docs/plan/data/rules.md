# 규칙 — `CL9Rules`

**게임에 하나뿐인 에셋이다.** 소리 · 죽음 처리 · 밤 시계 · 운반 마찰 —
캐릭터마다 다를 수 없는 값이 여기 있다.

몸 수치(속도·캡슐·스태미나·체력)는 [character.md](character.md)에 있다.

**점프의 판정 역할은 딱 하나 — 낮은 장애물 통과다** ([segkind.md](segkind.md) 점프 통과 셋).
거리·소음·감각 판정은 전부 평면(2D) 기준이다 — 3D 거리로 재면 점프 스팸이 회피 기술이 된다.

**운반은 리썰식 퀵슬롯이다** (2026-09-13 — 손 하나+품+R 교체+`SwapTime` 1.2초 폐기). `QuickSlots` 칸 중 활성 칸
하나만 손에 들리고 나머지는 데이터로 따라다닌다. 휠·숫자키 전환은 **즉시**이고 잠금 시간이 없다. 두 손
아이템(`HoldPose` Large)을 들었거나 수레를 미는 동안은 전환·줍기가 잠긴다. 운반 마찰은 칸 수 상한(꽉 차면
못 줍는다)·두 손 잠금·무게 감속·달리기 흔들림에서 나온다 — [../../systems/inventory.md](../../systems/inventory.md).

**먹기는 우클릭 길게다** (2026-09-13 — 옛 "좌클 길게" 폐기). 우클 탭은 스캔 그대로이고 `UseHoldTime`을 넘기면
활성 칸의 요리를 먹는다. 좌클은 누르면 공격 대기, 떼면 휘두르기(리썰 삽 방식) — 대기는 무한이고 대기 시간이
피해를 바꾸지 않으므로 대기에는 열이 없다. 대신 휘두른 뒤 **언제** 맞느냐가 `SwingHitStart`~`SwingHitEnd`
두 열이다: 그 구간 동안 손에 든 것의 히트박스(아이템 메시의 경계 구)가 지나간 자리에 닿은 몬스터가 전부 맞는다.
무엇을 맞히느냐는 사거리 수치가 아니라 휘두르기 애니메이션이 정한다 (2026-09-15, 옛 "사거리 200cm·정면 부채꼴" 폐기).

운반 흔들림은 바 없이 화면 흔들림 진폭으로 읽힌다 (게이지를 띄우면 "관리하는 자원"이 되어
긴장이 사라진다는 판단). 만충의 효과: 손의 취약물이 금 간다 (초안 —
[../../systems/character.md](../../systems/character.md) 흔들림 절).

### 잡히는 순간 카메라가 범인을 본다 (2026-09-20)

잡힌 사람의 **POV에만** 피치·요 오프셋을 더해 덮친 몬스터가 화면에 걸치게 한다 — 컨트롤 회전·시선
입력·조준은 그대로다([../../goal/monster-pounce-hurt-readability.md](../../goal/monster-pounce-hurt-readability.md) B 절,
[../../systems/character.md](../../systems/character.md) 잡히는 순간). HUD 가장자리의 피격 방향 호는
표 bool 하나로 끈다. 네 값 전부 표현 전용이며 판정에 닿지 않는다.

| 컬럼 | 기본값 | 뜻 | 구 CCL8 상수 |

| `HurtLookTime` | 0.45 **초안** | 피치·요 오프셋이 목표에 닿기까지 (초, EaseOut — 도달 보장). **0 = 끔**(모디파이어가 아무것도 안 한다). 0.45 = `HurtFlashTime` 0.45와 같은 창(몸이 빨간 동안 카메라가 돈다)이고, 넘어짐 카메라 하강(`FInterpTo` 6/s, 시정수 0.17초)이 0.45초에 93% 끝나 둘이 함께 멎는다. 복귀는 일어나기 0.6초 동안이라 `0.45 + 0.6 = 1.05 ≤ KnockdownTime 1.5` — 진입과 복귀가 겹치지 않는다(로드 검사 Warning) | **신규** |

| `HurtLookYawMax` | 60 **초안** | 요 오프셋 한계 (도) — 공격자 방향이 시선에서 가로 반각 45°를 넘는 만큼만, 최대 이 값. **0 = 요 없음.** 45 + 60 = **105° 안**의 공격자는 화면 가장자리에 걸치고(옆 90°는 여유 15°), 그 밖(등 뒤 150°)은 카메라가 아니라 방향 호가 답한다. 더 크면 보던 방향을 빼앗는 느낌(검토 지적)이라 옆까지만 | **신규** |
| `bHurtDirectionIndicator` | true **초안** | HUD 가장자리 피격 방향 호를 그리나. **false = 호 없음**(빌드 없이). 리썰 컴퍼니에는 방향 표시가 없어(비네트·소리뿐) 장르 톤이 어긋나면 여기서 끈다 — 취향 결정 | **신규** |

같아야 한다. 로드 검사: `HurtLookTime`·`HurtLookYawMax` 유한·비음수, `HurtLookPitch` 유한(`Validate`,
Error); `HurtLookTime + 0.6 <= KnockdownTime`(캐릭터 행을 붙이는 자리, Warning). 다른 눈높이·키 큰

## 스태미나 표시 (카메라 셰이크 + HUD 바)

스태미나는 **카메라 셰이크**로 알린다 — 지치면 화면이 떨리고, 바닥날수록 세진다. 소유 클라
로컬 표현이고 판정·복제와 무관하다. 진폭·주기는 셰이크 에셋이 가지고, 표는 어느 에셋을
언제부터 켜는지만 정한다.

**여기에 HUD 바를 함께 둔다** (2026-09-05 번복 — 위 예외 절과 같은 결정). 흔들림만으로는
남은 양과 탈진 래치 해제 시점이 안 읽힌다. 운반 흔들림은 여전히 바 없이 흔들림만이다.

**셰이크는 규칙 컬럼이 아니라 셰이크 표에서 읽는다** (2026-09-05 결정 — 앞으로 흔들림이
늘 때 규칙에 컬럼을 늘리지 않고 표에 행만 추가한다). `UCL9ShakeTable`(`ShakeTable`,
`UCL9UITable`과 같은 모양)의 `Rows`에 이름→`FCL9ShakeInfo{ Shake, StartAt, Scale }`로 등록하고,
캐릭터가 `CL9ShakeNames::Stamina` 행을 조회한다. 게이지 = (StartAt−Stamina)/StartAt, 0에서 만충.

| 행 (`Rows` 키) | 필드 | 뜻 |
|---|---|---|
| `Stamina` | `Shake` | 지쳤을 때 재생할 카메라 셰이크 (`UCameraShakeBase` 소프트 클래스) |
| `Stamina` | `StartAt` (0.5) | 정규화 스태미나가 이 값 아래부터 흔들림 |
| `Stamina` | `Scale` (1.0) | 재생 세기 = 게이지 × `Scale` (게이지형 행) |
| `Hit` | `Shake` | 휘두르기가 몬스터에 닿은 순간 공격자 카메라가 한 번 튕긴다 (`CS_HitShake` — 사인파 Pitch −3°@4Hz·0.12초, 짧고 날카롭게) |
| `Hit` | `Scale` (1.0) | 재생 세기 — 원샷 행은 `Scale`이 곧 세기다 |
| `Hurt` | `Shake` | 잡혀 넘어진 순간 피해자 카메라가 한 번 크게 흔들린다 (`CS_HurtShake` — 펄린 Roll, 묵직하게) |
| `Hurt` | `Scale` (1.0) | 〃 |

**`Scale`은 2026-09-18에 더한 배율 열이다** (사용자 "꺾이는 정도를 표에서 세팅") — 원샷 행은 `Scale` 세기로,
게이지 행은 게이지 × `Scale`로 재생한다. 진폭·주파수·블렌드는 여전히 셰이크 에셋 안에 있고 표는 배율만
갖는다 — 2026-09-05 "셰이크 값은 표 열로 두지 않는다"의 유일한 예외다.
`Hit`·`Hurt`는 **원샷 행이라 `StartAt`을 보지 않는다** — 게이지가 구동하는 것이 아니라 순간 사건이므로
`Scale` 세기로 한 번 재생할 뿐이다. 행이나 에셋이 비어 있으면 셰이크만 조용히 빠지고 나머지는 그대로 돈다.

**던지기 원점에 점프 높이를 더하지 않는다.**
