# 헤드램프 — `headlamp`

**헬멧에 붙은 빛.** 머리에 쓰는 장비라 **손이 빈다** — 계란을 들고도 앞을 비춘다
(2026-09-05 사용자 결정 — decisions.md). 트럭에서 사는 장비([../equipment.md](../equipment.md))이고,
실물은 이 아이템 행이다. 손전등(`flashlight`)은 그대로 남는다 — 손에 드는 빛, 아이템 중 하나.

컬럼 정의는 [common.md](common.md).

---

## 모델 — 쓰면 손이 빈다

| 컬럼 | 값 (초안) |
|---|---|
| `CarrySlot` | **`Head`** — 주우면(E) 머리에 쓴다. 손·퀵슬롯·수레에는 안 들어간다 |
| `ActorClass` | `BP_CL9FlashItem` — 지향성 스포트라이트 (2026-09-11: `bEmitsLight` 컬럼 대신 클래스) |
| `LightRadius` / `LightIntensity` / `LightConeAngle` | **1800cm / 16000 / 26°** — 손전등과 같은 값 (2026-09-16 올림, 09-17 PIE 확정 — [flashlight.md](flashlight.md)) |
| `LightScattering` | **8** — 손전등과 같은 값 (2026-09-17, 볼류메트릭 안개 속 빔 후광) |
| `bLightLostInPocket` | 해당 없음 (퀵슬롯에 안 들어간다 — 머리에 쓴다) |
| `bFragile` | false |
| `Weight` | 0 (초안 — 머리에 쓴 것은 짐이 아니다) |
| `ValueMin/Max` | 미정 |

- **쓰는 것은 줍기와 같은 E 한 번이다** — 손이 차 있어도 쓸 수 있다. 이미 쓰고 있으면 두 번째는 못 쓴다.
- 켜고 끄기는 `F`(`IA_Flashlight`) — **F는 헤드램프 전용**이다(손전등은 좌클, 2026-09-12). 쓸 때는 꺼진 채 시작.
- **벗기는 없다** (현재 설계). 잡혀 넘어져도 흘리지 않고, 밤이 끝나도 쓴 채다.
- 빔은 착용자의 시선을 따른다 (1인칭 카메라에 붙는다). 다른 사람 화면에서는 몸의 방향만 따르고
  위아래는 안 따른다 — 후속.

## 정전과의 관계

**정전이 와도 헤드램프는 켜져 있다.** 정전은 목적지의 시설(내부 시스템)을 죽이는 것이지 내가 가져온
장비를 죽이는 게 아니다 (2026-09-05 결정). 손에 든 손전등의 "정전이면 꺼진다" 규칙은 그대로다 —
[../../../systems/light.md](../../../systems/light.md).

## 지급·매매

- **트럭 패널에서 산다** (4f). 가격·`UnlockDay`·`MaxOwned` 미정 — [../equipment.md](../equipment.md).
- 4f 이전 테스트에서는 **바닥에 놓아 준다** (`Lvl_Flat` 트럭 패드 옆에 하나, 또는 `cl9.additem headlamp`).
- 벗을 수 없으므로 팔 수 없다 (현재 설계).
