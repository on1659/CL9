# 손전등 — `flashlight`

**손에 드는 빛.** 내장 기능이 아니라 아이템이다 (2026-09-01 결정 — decisions.md).
"손전등이 주 광원"([../../loop.md](../../loop.md))의 실물.

컬럼 정의는 [common.md](common.md).

## 모델 — 빛 vs 짐

| 컬럼 | 값 (초안) |
|---|---|

| `ActorClass` | `BP_CL9FlashItem` — **지향성 스포트라이트**, 좌클(`UseAction` `ToggleLight`) 토글 (2026-09-11: `bEmitsLight` 컬럼 대신 클래스) |
| `LightRadius` / `LightIntensity` / `LightConeAngle` | **1800cm / 16000 / 26°** (2026-09-16 — 800 / 6000 / 32°는 "바로 앞만 비춘다"는 피드백으로 올림. 헤드램프 행도 같은 값. 09-17 PIE: 참고 영상 대역, 확정. 빔이 시선에서 12° 왼쪽으로 빗나가는 그립 문제는 별건) |
| `LightScattering` | **8** (2026-09-17 — 볼류메트릭 안개 속 빔 후광, light.md. 헤드램프 행도 같은 값) |
| `bLightLostInPocket` | true — **활성 칸이 아니면 꺼진다** (비활성 칸은 액터가 없어 자연히 꺼진다; 열 이름은 옛 품 시절 그대로 — 2026-09-13 퀵슬롯) |
| `bFragile` | false (초안) |
| `Weight` | 미정 |
| `ValueMin/Max` | **미정 — 팔 수 있다** (여느 아이템과 같은 규칙. 이더 눈금에서 역산) |

> 2026-09-05: **머리에 쓰는 헤드램프([headlamp.md](headlamp.md))가 생겼다** — 트럭에서 사는 장비로,
> 쓰면 손이 빈 채 비춘다. 아래 "빛 vs 짐" 교환은 헤드램프를 사기 전(또는 잃은 뒤)의 이야기가 된다.
> 손전등은 아이템 중 하나로 그대로 남는다.

**활성 칸에 들어야 빛난다. 계란을 손에 들려면 칸을 바꿔야 하고, 그 순간 손전등은 꺼져 어둠이다.**
이게 이 게임의 빛 경제다:

- 혼자면: 빛과 짐을 칸 전환(휠·1~4)으로 번갈아 든다 — 전환은 즉시지만 **빛과 짐을 동시에 손에 못 든다**는
  것이 마찰이다 (2026-09-13 퀵슬롯 — 옛 `SwapTime` 1.2초는 폐기, [../rules.md](../rules.md) 운반)
- 팀이면: 한 명이 불을 들고 한 명이 짐을 든다 — 분업이 창발한다
- 놓고 비추기: 스탠드 램프(`standing_lamp`)가 이 문제의 장비 해법이다
  ([../equipment.md](../equipment.md))

## 지급·매매·분실

- **기본 지급은 손잡이다 — 줄 수도, 안 줄 수도 있다.** 프로토타입에서는 편의상 1개 지급한다.
  지급 여부·개수 값의 자리는 미정 (rules 또는 progression의 일자 덮어쓰기 후보)
- **팔 수 있다** — 창구에서 여느 아이템처럼 판다. 판 만큼 어둠이 그 대가다
- 잃거나 판 뒤에는 **트럭 패널에서 산다** (초안 — [../equipment.md](../equipment.md)에 행 추가 후보, 가격 미정)
- 여느 물건처럼 던질 수 있고 떨어뜨릴 수 있다 — 두고 오면 잃는다 (장비 분실 규칙)

## 정전과의 관계

**정전이 오면 손전등도 죽는다** ([../../loop.md](../../loop.md)) — 아이템이어도 예외 없다.
정전 후의 빛은 헤드램프와 스탠드 램프뿐이다 (발광 아이템은 2026-09-11 폐기). 상세는
[../../../systems/light.md](../../../systems/light.md).

## 미결

- 켜짐/꺼짐 토글 — 들고 있을 때 **좌클**(`IA_Use`, 행 `UseAction`=`ToggleLight`; 2026-09-12 F에서 이동, F는 헤드램프 전용 — [../../../systems/input.md](../../../systems/input.md))
- `ValueMin/Max`·구매 가격 — 이더 눈금에서 역산
- `Weight` — 빛을 드는 것도 짐인가 (0이면 트레이드오프가 약해진다)
