# 전체 구조

## 한 줄

**동물이 주인인 장소에서 재료를 훔쳐다, 푸드트럭에서 요리해 파는 1~4인 협동 추출 게임.**
**그런데 모두가 같은 편은 아니다** — 판마다 0~1명이 몰래 임포스터가 된다 (2026-10-11, [../goal/loop-rework.md](../goal/loop-rework.md)).

표적은 Steam 리슨 서버 협동 멀티다. 판정은 호스트가 하고 Steam은 전송만 한다.

## 큰 루프

```
        ┌─────────────────────────────────────────────────────┐
        │                                                     │
   정차 ─→ 주문서 수령 ─→ 목적지 선택 ─→ 원정 ─→ 귀환 ─→ 요리 ─→ 납품 ─→ 구매 ─┘
```

칸마다의 상세는 [loop.md](loop.md). 2026-10-11 개편(3판마다 회사 정산·구매, 이더 + 개인 소유 외부 재화, 임포스터)은
[../goal/loop-rework.md](../goal/loop-rework.md) — 아직 구현 전이다.

**주문서가 이 루프의 엔진이다.** 쿼터가 "몇 킬로"가 아니라 "오늘 오믈렛 3, 꿀버터 1"이라서,
무엇이 필요한지가 어디로 갈지를 정한다. 무게제로 하면 최저가 재료 반복 채집이 정답이 되어
요리도 목적지 선택도 장식이 된다.

## 무엇이 게임을 재미있게 만드는가

| | 어떻게 |
|---|---|
| **어둠** | 어둠이 기본이다. 손전등 빔(도달 1800cm — [data/item/flashlight.md](data/item/flashlight.md)) 밖은 캄캄하고, 정전이 오면 손전등도 꺼진다 |
| **마찰** | 계란은 깨지고, 짐을 들면 느려지고, 퀵슬롯 네 칸이 차면 더 못 줍고, 두 손 물건을 들면 칸 전환이 잠긴다 — 이 마찰이 게임이다 ([data/rules.md](data/rules.md) 운반) |
| **코미디** | 잡혀도 바로 죽지 않는다(닭 기준). 넘어지고, 친구가 웃는다 — 짐은 죽을 때만 흘린다 (2026-09-15, [loop.md](loop.md) 원정) |
| **읽히는 위협** | 닭은 통로 중앙으로 뭉툭하게 움직인다. 무엇을 하려는지 읽을 수 있어야 대응이 실력이 된다 |
| **의심** | 판마다 0~1명이 몰래 임포스터다. 몬스터를 유인해 동료를 죽게 만들고 혼자 살아 돌아오면 외부 재화를 받는다. 그래서 **판 중간에 누가 임포스터인지 찾는 것도 재미다** — 찾아서 처치해도 외부 재화, 오인해도 패널티 없음. 보너스이지 필수가 아니다 (2026-10-11, [../goal/loop-rework.md](../goal/loop-rework.md)) |

## 코드 구조

**단일 모듈 `Source/CL9/` + 언리얼 표준 Gameplay Framework** (2026-08-31 확정 —
[../decisions.md](../decisions.md)). CCL8의 9모듈·순수 C++ 심(`CL9Sim`/`FCL9SimState`) 구조는
승계하지 않는다. 폴더 구성과 규약 전문은 [../conventions.md](../conventions.md) § 2~5.

### 판정은 한 곳에만 있다

```
GameMode (서버 전용)              판정·스폰·상태 전이 — 클라에는 존재하지 않는다
     │  권위 상태 기록
GameState / PlayerState / 액터    Replicated UPROPERTY · 20Hz
     │  자동 복제 + OnRep 콜백
클라 프록시                       판정 0 · 표현만
```

- **캐릭터는 이동만 갖는다.** HP·짐 같은 판정 상태는 PlayerState 소유다. 예외 하나 —
  이동에 영향을 주는 상태(달리기·스태미나·무게 감속)는 `FSavedMove`에 실어 CMC 예측 경로에
  둔다 (2026-09-01 결정: PlayerState 복제로 적용하면 러버밴딩이 난다 — conventions § 4 예외 ·
  systems/character.md. PlayerState는 표시 미러만)
- 게임 시간은 `GetServerWorldTimeSeconds()` 기준이다 (클라 시계와 자동 동기화)
- 캐릭터 이동은 `ACharacter` + 커스텀 CMC의 예측 이동을 그대로 쓴다 — 직접 만들지 않는다

## 데이터 주도

**수치는 전부 에셋에 있고 에디터에서 바꾼다.** 숫자 하나 고치려고 빌드하지 않는다.

종류(아이템·몬스터·목적지…)는 **하나당 DataAsset 하나**이고, 각각에 기믹을 붙일 수 있다.
표에 추가하면 찍혀 나오는 구조다. 상세는 [data/README.md](data/README.md).

대신 로드할 때 **관계 검사**가 돈다 — "지친 빈손 속도 > 닭 추격 속도" 같은 부등식이 깨지면
로그에 어느 줄인지 찍는다. 목록은 [economy.md](economy.md). 멀티에서 호스트와 클라의 숫자를
접속할 때 대조하는 장치(`CL9TuningHash`)는 **설계만 있고 아직 미구현**이다 (2026-09-21 확인).
