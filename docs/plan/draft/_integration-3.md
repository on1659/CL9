## 4. 재조정본끼리 남은 부딪침

여덟 파일은 같은 시각에 따로 고쳐졌다. 몬스터 넷은 서로의 재조정 전 판만 읽었고(구조 12절, 주인 13절, 떠돌이 근거와 한계, 새유형 12절), 아이템·맵·판 루프·메타는 몬스터 넷이 고쳐지기 전에 읽었다고 적었다. 그래서 아래 어긋남 대부분은 의견 차이라기보다 서로의 재조정을 못 본 데서 생겼다. 종 하나의 일에서는 카드 쪽을, 23종에 걸치는 틀에서는 구조 쪽을 먼저 보는 2차 통합의 기준을 그대로 쓴다.

## 6. 정해 달라는 것 모음

여덟 파일의 "정해 달라는 것"은 **155건**이다 — 구조 A 0·B 12·C 4(10절), 주인 A 0·B 6·C 2(11절), 떠돌이 A 1·B 8·C 5(끝 절), 새유형 A 0·B 6·C 4(10절), 아이템 A 0·B 15·C 6(7절), 맵 A 0·B 17·C 11(9절), 판 루프 A 0·B 27·C 6(끝 절), 메타 A 2·B 20·C 3(끝 절). 합치면 A 3·B 111·C 41이다. 같은 질문을 여러 파일이 물은 것은 하나로 합쳤고, 4절의 부딪침 가운데 어느 파일의 질문 목록에도 없던 것은 통합이 질문으로 더했다. 결과는 **A 3건·B 103건·C 37건**이다.

- **A — 구조를 바꾸는 큰 결정.** 사용자가 답해야 한다. 쥐의 새 규칙은 아이템(쥐덫)·맵(구멍 단서)·메타(몰래 역할 임무)가 함께 따라 바뀌고, 몰래 역할의 이름과 비밀 임무의 이더는 사용자가 고르기로 한 것이다.
- **B — 규칙 갈림.** 추천대로 가도 다른 역할이 흔들리지 않는다. 묻지 않고 추천대로 진행하며 여기에는 목록으로만 남긴다. 재조정본끼리 추천이 갈린 곳은 통합 추천을 적었다(B1~B17).
- **C — 수치.** 기본값으로 진행하고 표에서 바꾼다.
