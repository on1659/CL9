### 3.2 2차끼리 넘긴 것

다섯 문서가 서로를 읽지 못했으므로 아래는 모두 **미답**이다. "받는 문서에 우연히 같은 내용이 있나" 칸은 받는 쪽이 넘김을 보지 않고 스스로 적은 것이 넘김과 맞는지를 이 문서가 대 본 것이다.

## 4. 정해 달라는 것 모음

2차 다섯의 "정해 달라는 것"은 **109건**이다 — 조작 A 3·B 13·C 6(8절), UI A 2·B 17·C 6(10절), 시퀀스 A 4·B 23·C 8(9절), 스토리 A 3·B 14·C 2(8절), 아트 A 5·B 11·C 5(9절). 합치면 A 17·B 78·C 27이다. 여기에 통합3 6.1의 A 3건을 더하면 A는 20건이다. 이 문서는 다음처럼 정리했다.

- **A에서 합친 것 둘.** 몰래 역할의 화면 이름은 통합3 A2·UI A2(메타 A1)가 같은 질문이다. 아트 A1(범위)과 A3(빈 것 메시 몇 종)은 앞의 답이 뒤를 거의 정하므로 한 질문으로 묶었다.
- **A에서 B로 내린 것 넷.** 조작 A1(손으로 푸는 구출 입력 — 통합2 C6이 이미 "같은 입력"을 전제로 값을 맞췄다), 조작 A3(퀵슬롯 칸 수 — 통합3 B96·메타 B12가 이미 4칸 유지를 추천으로 진행 중이다), 시퀀스 A2(새벽 공개 모양 — 추천안은 지금 화면 위에 박자만 얹어 비용이 없고, 무대는 줄이 정해진 뒤 다시 볼 수 있다), 아트 A4(1인칭 처형 클립 — 비용 1.5일 안팎이고 시퀀스 B6과 합쳐 B86으로 둔다).
