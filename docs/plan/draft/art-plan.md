## 5. 제작 순서

10-2절의 원칙 — **첫 한 종으로 규격을 확정한 뒤에 대량 생산한다** — 을 이번 범위에 적용한다. 그 원칙의 예로 10-2절은 쥐(작고 새 스켈레톤)와 어미 닭(닭 공유, 메시만 큼)을 들었다. 이 문서는 쥐 대신 토끼를 후보에 올렸다. 쥐는 결정 #41로 규칙을 잃어 새 규칙이 미답이고(떠돌이 A-1), 떼 하나를 몬스터 하나로 그리는 방법도 기술 검토 전이라, 첫 종으로 보내면 규격이 아니라 규칙과 기술을 먼저 기다리게 된다.

### 5.1 첫 종 — 후보 둘과 추천

| 후보 | 끝까지 보내면 확정되는 것 | 얻는 것 | 비용·위험 |
|---|---|---|---|
| **토끼** — 추천 | 새 모델·새 스켈레톤의 사슬 전체: 컨셉 → 3D 초안 → 짧은 동작 시험(Headbutt와 플레이어 Tumble 2~3초) → 리그와 11클립 → FBX·manifest → UE 왕복 → `MonsterTable` 행·ABP → `/cl9film` 한 편 | 네발 규격(뼈 이름·계층·피벗·판정 크기 재는 법)을 눈먼 개·여우가 이어 쓴다. 규칙이 정해져 있어 기다릴 것이 없다(새유형 5절 "남은 미결 없음"). 새유형 초안도 첫 규격 후보로 토끼를 냈다(11절) | 약 8일(모델 3 + 클립 11개 2.75 + 게임 연결 0.5 + 규격 확정 덧비용 2, 추정). 판 중간 벽 구멍 높이와 몸 크기의 어긋남이 첫 종에서 드러난다(9절 B4) — 이것은 오히려 일찍 아는 편이 낫다 |
| 어미 닭 | 닭 스켈레톤에 메시 배율·새 클립 셋을 더하는 사슬: `MeshScale` 1.3 → 새 클립 3(Peck Pin은 2인) → 기존 ABP 가지 → 게임 연결 | 가장 싸다(약 2.5일 — 클립 셋 1.25 + 플레이어 짝 0.75 + 게임 연결 0.5, 추정). 작은 안의 닭 계열 셋이 같은 스켈레톤이라 바로 이어진다 | 새 모델·새 스켈레톤을 시험하지 않는다. 같은 스켈레톤에 클립을 더하는 사슬은 2026-09-15(반응 클립 15개)·09-20(PounceWindup)·09-21(Execute 2인)에 이미 세 번 통과했다. 그래서 대량 생산 전에 알아야 할 새 정보가 적다 |

**추천은 토끼다.** 10-2절이 첫 종에게 바라는 것은 "그 규격으로 나머지를 찍는다"인데, 큰 안의 새 스켈레톤 종이 열넷이고 작은 안에도 새 종이 토끼 하나뿐이다. 같은 스켈레톤에 클립을 더하는 사슬은 이미 검증되어 있으니, 첫 종은 검증되지 않은 사슬(새 모델·새 리그)을 맡는 쪽이 대량 생산의 위험을 더 많이 줄인다.

**같이 돌릴 짧은 시험 하나.** 10-2절은 짧은 동작 시험을 "가장 어려운 2~3초부터(탈 터짐, 얼굴에 붙기, 끌고 가기)" 하라고 한다. 작은 안에서 가장 어려운 2~3초는 **닭의 탈 터짐(Burst 1.8초)**이다. 토끼와 별개로 이 시험을 일찍 한 번 돌려 사용자 승인을 받아 두기를 제안한다 — 빈 닭이 어떤 스켈레톤을 쓰는지(9절 A5)가 이 시험에서 갈린다. GPU는 Blender 렌더와 Unreal 촬영이 겹치지 않게 차례로 쓰고, 다른 세션의 편집기 잠금을 먼저 확인한다(10-2절).

**첫 종이 확정하는 규격 목록(토끼를 보낼 때 카드에 남길 것).** 네발 뼈 이름·계층과 `root` 규칙, 피벗과 `MeshYawOffset`, 판정 크기(`Radius`)를 메시에서 재는 법, 클립 명명과 길이·fps·루프 검사, FBX 프로파일(동물 클립은 Interchange로만 넣는다 — 몬스터 README 2026-09-21), manifest의 치수·축 검사 항목, UE 폴더와 ABP를 복제하는 방식(`ABP_Chicken` 복제 → 종별 스켈레톤), 표 행을 잇는 순서, `/cl9film` 촬영 대본(평시·예고·공격·죽음 한 편).
