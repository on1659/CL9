# 첫 스테이지 — 양계장

첫 제작 결과: [henhouse_sample_01 제작 카드](henhouse_sample_01.md) — 8종 부품과 실내 아트 샘플.

**목적지 `henhouse`는 기존 기획. 아래 시각 방향은 첫 샘플용 초안이며 최종 아트 확정은 아니다.**

사용자 지정 레퍼런스는 **Lethal Company와 R.E.P.O.**다.
[방식·분위기 적용 기준](../reference-direction.md)을 함께 읽는다. 기존 Farmlands 팩은
치수와 재사용 자원의 기준이며, 최종 분위기는 두 참고 게임을 바탕으로 CL9에 맞게 조정한다.

## 분위기

“낮에는 평범했을 농장이 밤에는 이상하게 무서운 곳.” 유지·관리한 흔적이 있는 목조 양계장에
동물들이 주인처럼 돌아다닌다. 재료를 빼앗는 행위가 위협을 깨운다. 과도한 유혈이나 폐허 장식보다
닭의 큰 실루엣, 철망 너머 움직임, 물건을 든 채 지나가기 어려운 공간으로 긴장감을 만든다.

| 요소 | 첫 샘플 방향 |
|---|---|
| 형태 | 기존 Dreamscape Farmlands와 나란히 놓아도 어울리는 단순하고 두툼한 형태 |
| 목재 | 회갈색·바랜 황토, 넓은 판자, 거친 면. 미세한 흠집보다 큰 색면 |
| 금속 | 어두운 회색·부분적인 녹. 철망은 배경에서 눈이 피로하지 않게 |
| 볏짚·사료 | 탁한 노랑·갈색. 계란과 명도/실루엣이 구분되게 |
| 외부 조명 | 차가운 밤빛, 트럭 주변의 따뜻한 빛. 안개 농도는 UE에서 조절 |
| 내부 조명 | 드문 누런 작업등과 손전등. 전체를 밝히는 환경광은 피함 |
| 코미디 | 과장된 닭의 체형·허둥거림·흘리는 짐. 장식 문구보다 플레이에서 발생 |

색온도·노출·안개 밀도·정확한 팔레트는 아직 확정하지 않는다. 재질에 밤색을 구워 넣지 않는다.
빛의 도달 범위·정전 동작은 기존 [조명 시스템](../../systems/light.md)을 따른다.

## 첫 제작 묶음 — 우선순위 초안

1. 500cm 벽 한 장: 기존 팩과 비교할 스타일/치수 기준물.
2. 둥지/계란 받침 소품 하나: 계란이 놓일 면과 손이 닿는 높이를 검토.
3. 작업등 외형 하나: 본체·발광 면 분리, UE 광원은 별도.
4. 계란 날것·익음·탐: 아이템 자동 배율과 상태 가독성 검증.
5. 위 에셋과 기존 팩을 놓은 짧은 통로 샘플: 플레이어 높이에서 정면·코너·손전등 장면 확인.

통로 샘플은 아트 검수용 `.blend`다. 검수 후 개별 조각을 납품하고 게임 배치는 모듈 표를 따른다.
닭 신규 모델은 기존 닭과 크기·실루엣·모션을 비교한 뒤 별도 카드로 착수한다.
이미 보유한 벽·울타리·소품은 우선 재사용/비교하며 동일 물건을 전부 다시 만들지는 않는다.

## 샘플에서 결정할 것

모델의 둥근 정도, 표면 디테일 밀도, 낡음의 강도, 계란 대비, 동물의 과장 비율.
같은 카메라·노출로 중립광과 밤 장면을 비교하고, 어두워도 출입구·발밑 장애물·재료가 읽히는지 확인한다.
