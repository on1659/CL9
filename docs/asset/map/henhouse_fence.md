# 양계장 판자 울타리

`fence/henhouse` 개별 반복 파츠. 현재 `wall` seg 높이288cm, 시야 차단 설정을 따른다.
현재 팩 실측201.44×24.01×202.47cm 대신 CellSize500의 약수인 **250×24×288cm**로 제작한다.
높이를 게임 값에 맞추어 위쪽 비균일 배율을 줄이고, 새 게임 치수/기능을 추가하지 않는다.

- 촘촘한 세로 판자, 두 가로 보강대, 금속 체결부. 불투명 형태로 시야 차단 규칙과 일치.
- 로컬 X 길이/Y 두께/Z 높이, 바닥 중앙 피벗, 연결면 X±125cm. 장식은 바운드 안에 둔다.
- 반복 끝 기둥은 반 폭씩 제공하여 2장 접속에서 한 기둥 폭이 된다.
- UV0, 버텍스 색 목재/철물 2재질, LOD0 목표4,000 tris 이하.
- 닫힌 UCX 상자1개로 경계를 막는다. 정적 구조물이므로 리그/클립 N/A.
- UE 임포트/치수/충돌과 2장 이음매·90도 회전만 작은 검수 배치에서 확인한다.
  전체 맵 조립/시드별 배치는 별도 작업. 기존 PieceTable은 검증 전 교체하지 않는다.

근거: [파츠 계약](README.md), [소비 경로](../../systems/asset-swap.md),
`CL9SiteMap.cpp` ComponentFor의 BlockAll/Visibility 설정.

결과: 250×24×288cm, 1,128 tris/624 vertices, UV0/2재질/UCX1.
원본·FBX·중립/야간/손전등 렌더, UE 임포트와 1월드 이음매/회전/충돌 검사 저장.
[013 검수](../iterations/013.md). 최종 테마 연결/이동 시각/2인/LOD 성능은 미완료다.
