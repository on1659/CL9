# henhouse_sample_01 — 첫 양계장 제작 샘플

작성: 2026-09-10 · 상태: 제작됨 / Blender 실측·야간 렌더 검수됨 / UE 미검수

## 범위

Blender MCP에서 만드는 첫 스테이지 아트 샘플. 10×15m 실내와 앞마당 일부.
5m 벽 조각과 개별 소품을 반복 배치한다. 게임 모듈 표의 완성이나 플레이 가능한 UE 레벨은 아니다.
리썰의 어두운 작업 공간과 R.E.P.O.의 큰 형태·운반물 가독성을 CL9 농장 소재에 적용한다.
기존 팩을 직접 이식하지 않고 새 원형으로 제작하며, 이후 UE에서 팩과 나란히 비교한다.

실측 치수·삼각형·재질 슬롯은 `ArtSource/map/henhouse_sample_01/export/manifest.json`에 기록한다.
원본: `ArtSource/map/henhouse_sample_01/henhouse_sample_01.blend`
제작 스크립트: `Tools/Blender/build_henhouse_sample.py`
샘플은 애니메이션/리깅을 포함하지 않는다. 이번 검증은 환경 조각과 재질·조명·스케일이다.

## 검수 계획

- Blender: 에셋 실측, 중립광/작업등/손전등 미리보기, 반복 벽 이음매, 156cm 카메라.
- 납품: 분리 FBX, 머티리얼 색/거칠기 메타데이터, UV 포함 원본.
- UE: 미실행. 크기·축·충돌·재질·아이템 자동 배율과 모듈 표 연결은 후속 검수.
- 제작 경험을 공통 규격에 확정 반영하는 것은 UE 왕복 검수 이후.

## 실제 납품/검수 결과

- Blender 5.2.1, MCP로 생성·배치·FBX 내보내기. 기존 `Scene`은 보존하고
  `CL9_HH01_KIT`(원점에 겹쳐 놓은 개별 원본)와 `CL9_HH01_STAGE`(조립 샘플)를 추가했다.
- 개별 Static Mesh FBX 8개, 합계 4,928삼각형. 각 메시 UV 1개, 재질 슬롯 1~2개.
- 벽 두께 실측 33cm를 발견해 **500×40×400cm**로 수정 후 FBX 재출력.
- 상수 Base Color/Roughness/Metallic 재질 사용. 이미지 텍스처 없음. `manifest.json`의
  선형 색·거칠기·금속·발광 값을 UE에서 재구성해야 한다. 표면 낡음·때·텍스처는 후속 제작.
- `preview/form_check.png`: 밝은 형태 확인용 첫 렌더(벽 두께/표지 수정 전).
- `preview/night.png`: 작업등을 줄인 야간 샘플, 156cm 눈높이.
- `preview/flashlight_detail.png`: 둥지 가까이에서 손전등만 추가한 검수용 시점.
- 코드의 셰이더 표시 이름이 한글 환경에서 달라 실패해 노드 타입으로 찾도록 수정했다.
  향후 MCP 스크립트에서도 UI 번역 문자열을 식별자로 사용하지 않는다.

## 남은 것

표면 마모/볏짚·철망 디테일, 외부 출입구/마당 아트, 계란 요리 상태,
몬스터와 리깅/애니메이션, 콜리전/LOD, UE 왕복 및 실제 팩과 비교는 아직 진행하지 않았다.
표지·빔·바닥 선은 조립 샘플 소품이며 8개 납품 FBX에 포함되지 않는다.
현재 샘플은 넓은 공간의 분위기 검증이다. 게임 모듈의 동선·층간 연결·전체 첫 스테이지 완성을 뜻하지 않는다.
