# 마당 바닥과 벽걸이 표식

- 마당 바닥500×500×30cm, 바닥 중앙 피벗. 낮은 흙 표면과 자갈, 500cm 경계에서 이어지는 색.
  흙면29.5cm/자갈 최고30cm, 단순 충돌면30cm이므로 흙면과의 최대0.5cm 차이를 기록한다.
  편집용 자연 크기와 현재 Size/100 Stretch용 중심100cm FBX 제공. UV0/버텍스색/UCX1.
- 표식4종: 출구 화살표, 사료 곡식, 조리 팬, 닭장 계란. 각각60×40cm 판과 뒤쪽 부착 앵커.
  기호는 두께 있는 메시이며 외부 글꼴/그림 파일 의존성이 없다. 금속 테두리와 불투명 색판.
  벽걸이 소품이라 별도 이동 방해 충돌은 제공하지 않는다. 실제 배치 시 NoCollision을 사용한다.

정적 환경 파츠로 리그/클립 N/A. 표식은 고정된 글자 대신 색과 그림으로 구별한다.
