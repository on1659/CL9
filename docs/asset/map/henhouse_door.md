# 양계장 일방향 출입문 파츠

현재 `door/henhouse` 첫 변형 실측131.9873×31.0185×256.4243cm.
새 문짝 폭은 동일하게 유지하고 높이256.4243cm/두께16cm로 제작한다.
원본은 오래된 청록색 판자문, 철제 경첩, 안쪽 노란 밀대와 출구 화살표다. 문틀은 포함하지 않는다.

- X 길이/Y 두께/Z 높이. 경첩 쪽 왼쪽 아래 원점, 문짝 바운드 X=0..131.9873cm.
- UV0/목재·철물 2재질. LOD0 목표4,000 tris 이하. 닫힌 단순 UCX1을 독립 배치용으로 제공.
- 현재 ACL9FlapIn은 Visual NoCollision/Body Box 충돌이며, 안쪽 캐릭터에만 이동 충돌을 무시한다.
  실제 회전/열림 애니메이션 소비처는 없다. 현 납품 리그/클립 N/A, 힌지/밀대 앵커 제공.
- Setup이 바운드 중심을 읽어 개구부 크기로 XYZ 각각 늘린다. 현재 flapIn 높이630cm이므로
  원본 세로 비례가 유지되지 않는다. Y방향 문에서도 액터 회전 없이 XYZ로 맞추는 코드를 확인했다.
  이 연결 문제를 원본에 찌그러진 형태를 만드는 방식으로 숨기지 않는다.
- 실제 데이터 표는 검증 전 교체하지 않는다. 필요한 소비 코드 변경은 별도 의존성으로 남긴다.
