## 현재 Stretch 소비 경로

`CL9SiteMap.cpp`의 Stretch 분기는 메시 바운드를 읽지 않고 `Size / 100` 배율과 셀 중심을 사용한다.
따라서 천장은 편집용 자연 크기 FBX와 별도로 **100×100×100cm/중심 피벗** FBX를 제공한다.
이 버전에(5,5,0.3)을 적용하면 500×500×30cm가 된다. 원본 형태와 UV/색은 함께 변환한다.
현재 ceiling과 floor가 공용 `box`를 쓰므로 천장용 역할을 분리하기 전 전역 box를 교체하지 않는다.
별도 역할 연결은 미완료이며 맵 생성기를 개편하지 않는다.
