# 009 — 손전등 / 헬멧형 헤드램프

Blender MCP로 두 장비를 새로 제작하고 원본/FBX/UV0/재질 값/미리보기를 저장했다.
손전등은 고무 그립·황색 몸체·스위치·렌즈, 헤드램프는 기획대로 아래가 열린 헬멧이다.
헬멧의 뜬 보강대/반사판과 안쪽으로 과하게 나온 브래킷을 수정했다.
긴 면이 곡면 안으로 파고드는 문제는 실제 메시 표면을 샘플링한 짧은 면으로 해결했다.
중립/야간/손전등과 헬멧 안쪽 렌더를 최종 수정 후 직접 확인했다.

| 원본 cm | 26.40×10.40×10.40 | 30.50×24.40×12.13 |
| tris / vertices | 1,528 / 792 | 2,844 / 1,444 |
| 재질 | 표면 VertexColor + 렌즈 | 표면 VertexColor + 렌즈 |

정적 장비이고 조명 토글은 엔진 SpotLight가 담당하므로 리그/클립 N/A. 렌즈 기본 발광0.

## UE 검수

- [최종 임포트](../evidence/009-portable-lights-imports.json): UE5.8.1,
  `/Game/CL9Art/Items/PortableLights`, 크기 오차 <0.000002cm. 두 재질 슬롯을 이름으로 연결.
  LOD3 생성. 이전 소유 해시를 대조한 뒤 수정 원본만 재임포트했다. Native MCP 에셋 이미지 확인.
- 실제 두 아이템 행에 임시 연결 → Native Unreal MCP StartPIE → 실제 `Server_PickPlace`,
  `Server_Flashlight` RPC → 상태/컴포넌트/부착 샘플링 → MCP StopPIE.
  정밀 샘플링과 RPC 호출은 기존 에디터 Python API를 사용했다.
- [실사용 증거](../evidence/009-light-use.json): **1월드 Lvl_Flat 로컬 상태/부착 통과**.
  손전등 줍기/켜기/끄기, 손전등을 든 채 헬멧 착용, 착용한 램프 우선 켜기/끄기 확인.
  손전등은 캡슐 상대(66,0,30), 헬멧은 카메라 상대(8,0,10)cm.
  자동화 준비 중 Python 속성 접근 오류를 수정했으며 실패 시도도 별도 증거 파일로 보존했다.
- [원래 데이터](../evidence/009-light-data-backup.json)로 검수 후 복구. 새 임포트 자산만 남겼다.
  C++/게임 수치/레벨 배치/PIE 참가 인원 설정은 바꾸지 않았다.

## 남은 게이트

렌즈와 실제 광원 원점의 전방 간격은 약11cm. 메시 자가 그림자와 실제 빔 화면을 확인해야 한다.
구체 충돌 기준 예상 바닥 간격은 손전등7.45cm/헬멧7.48cm이며 고기에서 확인한 공통 의존성이 남는다.
카메라/머리 간섭, 그립 화면, 정전, 2인 복제/타인 시점, LOD 시각/성능과 최종 데이터 연결 미완료.
상태·부착 수치 통과를 렌더/2인/최종 완료로 확대하지 않는다.

다음 제작은 프라이팬·냄비. 필수45개/최종 완료0개 유지. 맵 조립 제외.
