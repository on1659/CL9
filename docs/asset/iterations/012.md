# 012 — 삼각 받침 작업등

Blender MCP로 보호봉/확산등/삼각 받침/운반 손잡이/전원함을 제작했다.
86.95×75.60×179.60cm, 1,552 tris/836 vertices, UV0/2재질.
원본 `ArtSource/item/standing_lamp_a/standing_lamp_a.blend`, 개별 FBX와 manifest 저장.
바닥/광원/손잡이 앵커는 REF Empty와 manifest에 보존하고 FBX에서 제외했다.

- 중립·야간·손전등·발광 야간 렌더 4장을 직접 확인했다. 발광 렌더 후 원본 밝기0 복구.
- [UE 증거](../evidence/012-standing-lamp-imports.json): UE5.8.1 임포트 치수 오차 <0.000007cm,
  2재질/LOD3 생성, Native Unreal MCP 에셋 이미지 확인.
- `MI_StandingLamp_Off`/`On`: `LightStrength` 0/4 저장과 읽기 검증.
  4는 외형 검수용 값이며 게임 밝기/광원 범위 확정이 아니다.
- 실제 standing_lamp 데이터 행이 없어 게임 배율·운반·배치·정전·2인 검수 미연결.
  발광 표면 미리보기를 실제 UE 주변 조명 기능 통과로 기록하지 않는다.
- 충돌/LOD 시각·성능 및 게임 연결은 미완료. 데이터/레벨 배치 변경 없음.

필수45개/최종 완료0개 유지. 다음은 재사용 양계장 울타리 파츠. 전체 맵 배치 제외.
