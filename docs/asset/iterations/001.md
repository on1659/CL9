## QA 상태

샘플 8종+기준 큐브 임포트 완료. `../evidence/001-ue-import.json`에서 치수 오차 <0.003cm와 의도한 UCX 개수 일치를 확인했다. 상자 minZ=-0.5cm를 Blender에서 수정하고 재임포트했다. 벽/둥지는 3단계 LOD를 구성했다.

UE5.8 Interchange 변환에서 FbxImportUI의 auto_generate_collision=false가 충돌 임포트 자체를 끄는 문제가 있었다. UCX 대상에는 true와 one_convex_hull_per_ucx=true를 적용하고 결과 hull 개수를 대조했다. 달걀은 게임플레이 구체 충돌을 사용한다.

별도 `/Game/Tests/Lvl_AssetQA01`에서 2인 listen PIE를 실행했다. 양쪽에서 새 날달걀 메시, 배율 1.05, 바닥 접촉을 관찰했다. **집기 검증은 실패했다.** `../evidence/001-pie-interactions-retry.json`의 집기 후 attachment=false이며 거리/시작 위치와 주문 선택 상태를 진단 중이다. 이전 `001-pie-interactions.json`의 observed는 통과 증거로 사용하지 않는다.

기존 Chicken/Pig/Sheep ABP의 누락된 애니메이션/스켈레톤 관련 컴파일 오류도 발견했다. Play로 진행한 사실은 오류 수정 또는 몬스터 검수 통과를 뜻하지 않는다.

다음 검수: 집기/수납/투척 실제 상태와 2인 복제, 이동 충돌, 시각 및 성능. 전체 PIE·2인·성능 **아직 통과 아님**. 현재 원본/임포트와 실패 증거는 디스크에 저장되어 있어 중단 후 재개할 수 있다.
