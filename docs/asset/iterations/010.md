# 010 — 프라이팬 / 냄비

Blender MCP로 내부가 비어 있고 두께가 있는 팬과 에나멜 냄비를 제작했다.
팬의 긴 손잡이/걸이 구멍, 냄비 양쪽 고리/고정 탭을 포함한다. 냄비 손잡이를 외부로 조정하고
아래쪽 내벽이 외벽을 통과하던 부분을 수정했다. 최종 중립·야간·손전등 렌더를 직접 확인했다.

| 모델 | 원본 cm | tris / vertices | 재질 |
|---|---|---|---|
| frying_pan | 60.20×35.00×8.05 | 1,120 / 568 | 표면/손잡이 2슬롯 |
| pot | 36.80×53.00×26.00 | 1,804 / 912 | 표면/손잡이 2슬롯 |

원본 `ArtSource/item/cookware/cookware.blend`, 각 FBX/UV0/버텍스 색/재질 값/manifest 저장.
정적인 운반 소품으로 리그·클립 N/A. 프라이팬은 현재 요리 열원이 아니며,
냄비의 실제 행/동시 조리 기능은 아직 없는 것으로 구분한다.

## UE와 실사용 증거

- [임포트](../evidence/010-cookware-imports.json): UE5.8.1 `/Game/CL9Art/Items/Cookware`.
  두 모델 치수 오차 <0.000001cm, 두 재질 슬롯 연결, LOD3 생성. MCP 팬 에셋 이미지 확인.
  냄비의 게임 Radius/최종 배율은 행이 없으므로 null로 기록했다.
- 팬의 실제 Radius30 배율0.98831062, 표시 치수 약59.50×34.59×7.96cm.
- 실제 팬 행에 임시 연결하고 Native Unreal MCP로 Lvl_Flat 1월드 PIE 시작/종료.
  기존 에디터 Python API에서 실제 Server_PickPlace와 Server_ThrowChargeStart/Release RPC를 호출했다.
- [실사용 수치](../evidence/010-pan-use.json): 줍기/놓기/다시 줍기/던지기 후 위치 이동과
  손 인벤토리/부착/메시 일치 통과. 합성 부착이나 손 인벤토리 강제 설정을 사용하지 않았다.
- 던진 뒤 메시 하단 Z26.113cm, 구체 하단 Z0.091cm. **바닥 표현 간격26.022cm로 미통과**.
  동작 검수 성공을 전체 에셋 완료로 확대하지 않는다.
- [원래 데이터 참조](../evidence/010-pan-data-backup.json)로 검수 후 복구했다.
  게임 수치/C++/맵/참가 인원 설정은 바꾸지 않았다. 원본 및 UE 아트 에셋은 보존한다.

남음: 바닥 소비 경로, 실제 손잡이 그립/시점, 2인 표현, LOD 시각/성능, 최종 데이터 연결.
냄비는 실제 데이터/기능 미구현 의존성도 남는다. 필수45개/최종 완료0개 유지.
다음 제작은 수레. 전체 맵 배치·조립은 범위에서 제외한다.

재사용 개선: 정적 소품 비교 렌더를 `preview_static_pair.py`로 공용화했고,
검증한 UE 임포트/임시 행 연결 스크립트는 대상 경로와 manifest를 매개변수로 받는다.
기존 손전등 원본/UE 자산을 다시 제작하거나 재임포트하지 않았다.
