# 016 — 보·기둥·천장 구조 파츠

Blender MCP로 독립 파츠3종과 현재 Stretch 계약용 천장 내보내기 변형을 제작했다.
전체 맵/방 조립은 하지 않았다. 원본은 `ArtSource/map/henhouse_structure/`의 beam/pillar/ceiling.
세 파츠 비교용 `structure_review.blend`와 중립·야간·손전등 렌더3장을 저장하고 직접 확인했다.

| 원본 | 치수cm | tris/vertices | 재질/UV/충돌 |
|---|---|---|---|
| 보 | 500×28×32 | 508/280 | 2재질/UV0/UCX1 |
| 기둥 | 28×28×400 | 596/328 | 2재질/UV0/UCX1 |
| 천장 | 500×500×30 | 792/432 | 1재질/UV0/UCX1 |

정적 구조물로 리그/클립 N/A, 바닥 중앙 피벗과 접속 앵커 제공.
천장 두께30cm는 [현재 SegKind 조회](../evidence/016-structure-contract.json)로 확인했다.
현재 Stretch 코드가 `Size/100`과 중심 원점을 사용하므로 천장에 100cm 중심 피벗 FBX를 추가했다.
[432정점 복원 비교](../evidence/016-ceiling-restore.json) 오차<0.000001cm.
이는 원본 정점 비교이며 UE 셰이딩/LOD 전체 검수는 아니다.

## UE 검수

- UE5.8.1 [보](../evidence/016-beam-imports.json), [기둥](../evidence/016-pillar-imports.json),
  [천장2버전](../evidence/016-ceiling-imports.json) 임포트. 모두 치수 오차<0.0001cm/UCX1/LOD3.
  원본3종의 Native MCP 에셋 이미지 확인.
- [PIE](../evidence/016-structure-pie.json): 1월드 검수 파츠6개만 사용했다.
  보2장 간격0cm/90도 치수 일치. 천장 자연 크기와 100단위 버전에(5,5,0.3)을 적용한 결과
  모두500×500×30cm, 같은 하단 높이, 이음매 오차<0.0001cm.
  line/capsule 검사에서 보·기둥·천장 이음매 차단, 천장 아래 수평 이동 공간 비차단,
  아래에서 천장을 향한 캡슐 이동 차단 확인.
- [정리](../evidence/016-structure-fixtures.json): 검수6액터만 제거하고 원래 목록 일치 확인.
  검수 맵만 저장, Lvl_Flat 복귀/PIE 종료. 기존 데이터와 레벨 배치는 변경하지 않았다.

현재 floor/ceiling은 같은 box 역할을 공유한다. 전역 box 교체는 다른 조각까지 바꾸므로 하지 않았다.
천장 역할 분리/실제 연결은 미완료. 직접 걷기/운반 시각·2인·LOD 전환/성능도 미완료다.
