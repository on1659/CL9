# 020 — 철판 조리대

Blender MCP로 평판 철판·법랑 몸체·전면 환기 패널·고정 손잡이/다이얼을 제작했다.
[제작 카드](../map/kitchen.md), 원본 `ArtSource/map/kitchen/kitchen.blend`.
120×300×90cm/2,608 tris/1,424 vertices/UV0/3상수 재질/UCX8/바닥 피벗/+X 정면.
현재 조리 로직에 가동부가 없어 리그/클립 N/A. 손잡이1mm 돌출을 최초 임포트 전에 수정했고
manifest `handle_fit=true`로 기록했다. 중립·야간·손전등3렌더와 Native UE 에셋 이미지 확인.

- [소비처](../evidence/020-kitchen-consumer.json): Lvl_Flat의 기본 큐브가300×120×90cm.
  새 원본은 배율1/Yaw90으로 같은 세계 작업 면적을 복원한다. 상판 위 장식은 열 높이를 바꾸므로 제외.
- [UE5.8.1 임포트](../evidence/020-kitchen-imports.json): 치수 오차<0.00004cm/UCX8/LOD3.
  원본·임포트 해시 일치. LOD 생성과 실제 전환·성능 검수는 구분한다.
- [첫 PIE](../evidence/020-kitchen-pie-before-heat-fit.json): 줍기/놓기/가열 중 제거/익음→탐은
  진행됐으나 HeatZone이120×300cm로 상판300×120cm와 엇갈려 최종 검수 실패.
  BeginPlay가 세계 AABB 반경을 쓰면서 부모 회전도 상속하는 것이 원인이다.
- 검수 BP 인스턴스의 HeatZone을 Absolute Rotation=true/세계 회전0으로 보정했다.
  원래 BP나 게임 C++는 수정하지 않았다. **영구 연결 때 같은 설정을 적용해야 한다.**
- [최종1월드 PIE](../evidence/020-kitchen-pie.json): 실제 BP_CL9Kitchen + 실제 계란으로
  E에 해당하는 RPC 줍기→상판에 놓기→가열 중 다시 집기→다시 놓기→12초 익음/24초 탐을 확인.
  집었을 때 가열 None/진행도0/조리 대상 해제, 다시 놓으면 새 시간부터 시작했다.
  이동·조준은 검수용 설정이며 실제 키보드 이동/손 시각/2인 검수를 의미하지 않는다.
- 최종 상판 세계Z1090cm, HeatZone 중심Z1120cm/300×120×60cm로 일치.
  계란은 상판에 접지했고 구체 지지 간격0.000001cm/속도0. 검수 원본은 변경하지 않았다.
  익음/탐 계란은 현재 데이터의 기본 구체이므로 **계란 상태 아트 납품을 통과 처리하지 않는다.**
- [정리](../evidence/020-kitchen-fixtures.json): 검수4액터만 제거/원래29액터 확인,
  검수 맵만 저장 후 Lvl_Flat 복귀/PIE 종료. 실제 BP 기본값·데이터·사용자 레벨 변경 없음.

영구 BP 연결(열 영역 회전 포함)/기존 인스턴스 배율·피벗 보정/2인/LOD·성능은 미완료.
전체45필수 행 최종 완료0개, 조립 참고17행 제외 유지. 다음 제작은 납품 창구로 이어간다.
