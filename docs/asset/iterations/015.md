# 015 — 양계장 작업대

office RectangularTable 계열을 위한 독립 작업대 외형을 Blender MCP로 제작했다.
180×75×90cm는 신규 제작 초안이며 기존 테이블 실측 복제가 아니다.
목재 상판/철제 프레임/낮은 선반, 바닥 중앙 피벗, 상판90cm·선반25cm 앵커.
1,212 tris/664 vertices, UV0/2재질/UCX12. 단순 가구여서 LOD0 예산 하한보다 적다.
정적 소품으로 리그/클립 N/A. 조리/제작/서랍 기능을 새로 만들지 않았다.

- `ArtSource/map/henhouse_workbench/henhouse_workbench.blend`, FBX/manifest/3렌더 저장·확인.
- [UE 임포트](../evidence/015-henhouse-workbench-imports.json): UE5.8.1 크기 오차<0.000031cm,
  피벗/재질2/볼록 충돌12/LOD3 확인. Native MCP 에셋 이미지 확인.
- [PIE 증거](../evidence/015-workbench-pie.json): 정방향/90도 회전 파츠2개와 물리 구체1개만 사용.
  실제 물리 시뮬레이션으로 반경10cm 구체를 떨어뜨려 상판에 정착: 간격 약-0.000183cm,
  속도0.0014cm/s. 이는 검수용 기본 구체이며 CL9 아이템 줍기/놓기 통과 주장이 아니다.
  캐릭터 캡슐은 몸체 차단/옆 빈 공간 비차단, line trace는 선반 차단/상판 아래 중앙 비차단 확인.
- [정리](../evidence/015-workbench-fixtures.json): 소유한 검수3액터 제거, 원래 목록 일치,
  검수 맵만 저장하고 Lvl_Flat 복귀. 실제 데이터/맵 배치/C++ 변경 없음.

실제 모듈 연결, 게임 아이템 놓기/운반 시각, 2인/LOD 전환·성능은 미완료.
전체 맵 조립을 수행하지 않았고 최종 완료로 올리지 않았다. 필수45개/최종 완료0개 유지.
다음은 양계장 보/기둥 및 천장 등 재사용 구조 파츠. 현재 단위·피벗·충돌 도우미를 재사용한다.
