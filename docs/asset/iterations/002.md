# 002 — 계란 상태와 닭 전용 모델

2026-09-11. 이전 goal 턴은 진행 기록 저장으로 진전이 있었다. 이번 반복은 실제 제작물 추가다.

사용자가 모델 제작을 우선하라고 지시했다. UE 입력 문제의 장시간 진단보다 Blender 제작에
집중하되, 최종 UE 실사용 검수 게이트는 유지한다. 닭/거위/너구리/돼지/양 모두 계속 대상이다.

## 계란

- [제작 카드](../item/egg_states.md), `ArtSource/item/egg_states/egg_states.blend`.
- 5종 원본/FBX/manifest. raw는 기존 샘플을 이어 사용했고 cooked/burnt/cracked/broken을 새로 만들었다.
- 중립광/야간 렌더를 직접 확인했다. 긴 균열 리본이 메시 안으로 들어가 점선처럼 보이는 결함을
  발견하여 촘촘히 나누고 실제 껍데기 면에 투영하여 연속된 금으로 수정했다.
- broken은 안쪽 껍데기와 내용물 구분을 위해 3슬롯을 사용한다(작은 재료 목표 2슬롯에서 1개 초과).
  현재 1,228 tris이며 UE 동시 노출 측정 후 병합 필요 여부를 판단한다.
- UE 상태 연결/자동 배율/요리/파손/운반은 미완료다.

## 닭

- [제작 카드](../monster/chicken_a.md), `ArtSource/monster/chicken_a/chicken_a.blend`.
- 전용 신규 모델 10,196 tris / 5,218 vertices / 17개 변형 뼈 / Vertex Color 1재질.
- 실측 약 132.81×75.60×133.32cm. 신체 부위별 1개 뼈 가중치 1.0, 미할당 0.
- Idle/Walk/Run/LookAround/HitReact/WakeTelegraph/Catch/Death 8개 Action과 개별 FBX 생성.
- 걷기/달리기 지지 구간 목표 위치를 실제 두 뼈 다리 풀이로 맞췄고 평가된 발 위치를 확인했다.
- 중립/야간 및 동작 대표 프레임을 확인했다. Catch 발 관통, Death 바닥 관통과 날개 끝에 걸려 몸이 뜨는 결함을 수정했다.
- 최종 `ArtSource/monster/chicken_a/export/blender_animation_qa.json`: 8클립 바닥/루트 검수, 루프 4개 경계 일치, Walk/Run 지지 속도 오차 <0.0001cm/s. 각 FBX SHA256도 기록.
- Blender 5.2 영상 출력은 image_settings.media_type='VIDEO'를 먼저 설정해야 FFMPEG를 선택할 수 있다. 실제 API enum 조회 후 수정했다.
- `preview/walk_cycle.mp4`(24프레임), `run_cycle.mp4`(15프레임), 각 512×512/30fps 생성. Blender MovieClip 로드로 프레임 수/크기를 확인했다. 감사에 기록된 8개 FBX SHA256이 최종 파일과 일치한다.
- UE 임포트/AnimBP/상태 소비/속도 일치/2인 검수는 아직 없다.

## UE 입력 단서와 증거 관리

- 사용자 직접 관찰: Lvl_Flat 첫 실행은 움직이지 않고, F8 탈출 후 복귀하면 정상 조작된다.
  입력 포커스/possess 경로를 다음 PIE 검수에서 우선 확인한다. 아직 원인 확정 또는 수정하지 않았다.
- 재개 시 UE가 검수 레벨에서 Lvl_Flat으로 바뀌어 있었고, 집기 자동 테스트는 빈 인벤토리
  사전조건에서 중단했다. 사용자 플레이 상태를 초기화하지 않았다.
- `001-pie-initial.json`은 재개 조회에서 빈 worlds로 덮어써져 초기 PIE 근거로 사용하지 않는다.
  기존 interaction 파일과 스크린샷은 보존. 조회 스크립트 출력은 이제 Saved/asset-pie-current.json으로 분리했다.
- `qa_item_carry.py`는 실제 RPC/인벤토리/부착을 대조하며 수납 후 액터 재생성을 반영한다.
  아직 통과한 실행은 없고, 이번에는 모델 제작을 우선했다.

전체 완료 수는 0. 제작 진행과 UE 검수 완료를 구분한다.
