# 017 — 짧은 벽과 계단 디딤판

Blender MCP로 기존500cm 벽과 연결하는250/125cm 벽, 개별 디딤판을 제작했다.
원본 `ArtSource/map/henhouse_access_parts/`의 wall250/wall125/tread와 비교 장면 `access_review.blend`.
계단 전체나 맵은 조립하지 않았다. 정적 구조물로 리그/클립 N/A.

| 파츠 | 치수cm | tris/vertices | 납품 |
|---|---|---|---|
| 짧은 벽250 | 250×40×400 | 792/432 | UV0/2재질/UCX1 |
| 짧은 벽125 | 125×40×400 | 528/288 | UV0/2재질/UCX1 |
| 디딤판 | 263.9746×27.4194×30 | 220/120 | UV0/2재질/UCX1 |

디딤판 치수는 현재 문 폭과2×2 계단/610cm 층/31단 계산을 따른다.
현재 floor Stretch가100cm 중심 피벗을 요구하므로 XRun/YRun FBX 두 버전을 추가했다.
`stretch_export.py`에 해당 변환을 공용화했다. 이전 천장 원본은 재생성하지 않았다.

## 수정과 검수

- 앞 표시가 디딤판 깊이 밖으로0.6mm 돌출한 것을 수정 후 첫 UE 임포트.
  `tread/export/manifest.json`의 `marker_fit=true`, 재실행 금지.
- 첫 벽 렌더에서 심재·보강대·끝 기둥의 같은 평면이 겹쳐 검은 부분이 보였다.
  심재/보강대 폭을 기둥 사이로, 심재 높이를 상·하단 보강대 사이로 줄여 수정했다.
  두 벽의 `intersection_fit=true`, `top_fit=true`. 각 수정 후 FBX 재임포트와 최종3렌더 직접 확인.
  기존500cm 벽 원본은 수정하지 않았다.
- UE5.8.1 [250벽](../evidence/017-wall250-imports.json), [125벽](../evidence/017-wall125-imports.json),
  [디딤판3버전](../evidence/017-tread-imports.json): 모든 치수 오차<0.00005cm/UCX1/LOD3.
  자연 치수3종 Native MCP 에셋 이미지 확인.
- [최종1월드 PIE](../evidence/017-access-pie.json): 기존500→250→125 벽 이음매0/<0.000004cm,
  이음매 캡슐 차단. 디딤판 자연 크기와 방향별 복원 치수/높이/상면 충돌 확인.
  상단 면 수정 전 검사는 `017-access-pie-before-top-fit.json`로 보존하고 최종 원본에서 다시 실행했다.
- [정리](../evidence/017-access-fixtures.json): 검수6액터만 제거, 원래 액터 목록 일치 확인.
  검수 맵만 저장하고 Lvl_Flat 복귀/PIE 종료. 데이터/게임 코드/전체 배치는 변경하지 않았다.
- 마지막 렌더 출력에 다른 클라이언트 연결 재설정 로그가 있었지만 렌더 완료 메시지와 최종3파일을
  확인했고, 후속 Blender MCP 조회도 성공했다. 실행 중인 렌더 핸들은 없다.

wallHalf 자동 선택, 디딤판 전용 역할/방향 선택, 실제 계단 걷기·운반/2인/LOD 전환·성능은 미완료.
소품/방향 변형을 전역 box에 임의로 연결하지 않았다. 필수45개/최종 완료0개 유지.
