# 023 — 푸드트럭 본체와 뒤 계단

Blender MCP로 고정 거점 본체와 재사용 가능한 별도 계단을 제작했다.
[제작 카드](../map/food_truck.md). 전체 맵 조립이나 차량 운전 기능은 범위 밖이다.

|---|---|---|---|
| `ArtSource/map/food_truck/body/food_truck.blend` | 630×353.5×325.1 | 5128 / 2850 | 4 / 24 |

각 FBX/UV0/상수 재질/바닥 중앙 피벗/+X 정면. 고정 운전석·차양·출입구로 리그/클립 N/A.
원본 각각 중립·야간·손전등과 본체 후면 호환 렌더, UE Native 에셋 이미지 확인.
후면 호환 화면은 별도 본체/계단/기존 조리대를 복사한 검수 화면이며 합친 납품 메시가 아니다.

- [최종 Blender 검수](../evidence/023-blender-final.json): 닫힌 manifold 면, 면적0 없음,
  유한 UV, 치수/삼각형/재질/UCX 수와 FBX→UE 해시 일치.
- [본체 임포트](../evidence/023-body-imports.json), [계단 임포트](../evidence/023-steps-imports.json):
  UE5.8.1/LOD3 생성, 치수 오차<0.00007cm. LOD 시각·성능은 아직 미검수.
- 옆판/격벽의 겹친 모서리 면, 앞유리 막대 각도, 계단 표시와 발판의 동일 평면을 수정했다.
  철제 발판은 표시/충돌 상면보다1mm 낮다. 후면 램프는 출입구에서 양 끝 기둥으로 옮겼다.
  그릴 베벨의 중복 정점과 면적0인8면은 표면 위치를 바꾸지 않고 정리했다(5144→5128tris).
- 초기 재생성은 Blender join 잔여 데이터의 재질 참조 때문에 중단됐다. 다른 씬은 보존하고,
  실제 객체에서 쓰지 않는 해당 초안 재질 이름만 바꿔 복구했다. 전체 orphan purge 없음.
  MCP 결과 문자열에 포함된 오류도 확인해야 하며 성공 여부를 isError만으로 판단하지 않는다.
- [초기 PIE](../evidence/023-food-truck-pie-before-clearance-fit.json)에서 출입/통로 캡슐 차단.
  뒤 차축을42cm 뒤로 이동하고 안쪽 덮개를 후벽 안에 맞췄다. 조리대 앵커는30cm 앞으로 이동,
  덮개와 조리대 footprint 사이6cm, 조리대 옆 벽까지119cm를 확보했다.
- [수정 후 PIE](../evidence/023-food-truck-pie.json): 반경39/반높이90cm 실제 캡슐의 출입/통로
  sweep 통과, 벽/격벽/천장 차단. 4단 지지 높이16/32/48/64cm, 계단과 트럭 바닥64cm 일치.
  HitResult 필드가 Python에 노출되지 않아 line trace 끝점 이분 탐색으로 지지 높이를 측정했다.
- [실제 캐릭터 이동](../evidence/023-food-truck-walk.json): 초기 위치만 설정한 뒤
  AddMovementInput→실제 CharacterMovement로 계단 상승→조리대 옆 진입→후진 하강/지면 복귀.
  게임 시간 약4초, 수평 이동 중 위치를 강제로 갱신하지 않았다. 키보드 입력/시점/2인 검수는 아니다.
- 이동 검수 뒤 변경은 비충돌 램프와 위치가 같은 그릴 중복 정점 정리뿐이다.
  최종 재임포트/치수/충돌 수/표면 검수 완료. 이동용 UCX 형상은 바꾸지 않았다.
- [정리](../evidence/023-food-truck-fixtures.json): 검수4액터만 제거, 원래29액터 보존,
  검수 맵만 저장 후 Lvl_Flat 복귀/PIE 종료. 사용자 레벨/원래 BP/데이터/C++ 변경 없음.

영구 거점 BP 연결, 게임 조명/시점·운반 상태,2인 표현,LOD·성능은 미완료.
전체45필수 행 최종 완료0개, 조립 참고17행 제외 유지. 다음은 farmer_a 몸/팔의 실제
Manny/FPP 리그 추출과 외형 제작이다. 기존 리그 호환을 확인한 뒤 필요한 동작을 만든다.
