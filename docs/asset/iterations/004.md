# 004 — 닭·너구리 UE 스켈레탈 왕복

2026-09-11. 이전 턴은 너구리 프레임 감사/렌더로 진전이 있었다.

- UE 5.8.1, `Monsters/ChickenA`, `RaccoonA`: 메시 2개, 종별 스켈레톤,
  각 8클립과 VertexColor 재질 임포트. 현재 Native MCP AssetTools에 FBX import가 없어
  임포트/정밀 포즈 샘플링은 에디터 Python, 뼈/바운드/재질 조회·연결·이미지 검수는 MCP 사용.
- `evidence/004-creature-imports.json`: 크기 오차 <0.00002cm, 색 속성 있음,
  16클립 스켈레톤·재생 길이 일치, FBX 해시 기록.
- `evidence/004-creature-pose-comparison.json`: 전 프레임 발 위치 UE↔Blender 비교.
  Y축 반전 반영 시 닭 최대 0.000046cm, 너구리 최대 0.007582cm. root 변위 0.
  이 검사는 발 위치에 한정되며 전체 피부 변형/실제 행동 검수까지 증명하지 않는다.
- 닭 기본 회색 재질 슬롯을 MCP set_material로 수정. 추가로 VertexColor 출력 이름 `RGB`는
  BaseColor에 연결되지 않음을 발견했다. 빈 출력 이름으로 연결하고 SkeletalMesh usage를 설정.
  수정 후 MCP CaptureAssetImage로 닭 볏/몸 색과 너구리 무늬 확인. 임포트 스크립트에도 반영.
- UE가 armature wrapper를 추가한다(닭 17 변형 뼈+wrapper 1). 단위 변환으로
  wrapper world scale=100이지만 실제 메시 크기/발 위치는 일치한다. 임의 뼈 삭제/스케일 적용 없음.
- 검수 맵에 임시 닭 액터 배치/캡처 후 그 액터만 제거. QA 맵 저장 후 `Lvl_Flat` 복귀.
  실제 게임 몬스터 데이터/AnimBP/C++/맵 배치 변경 없음. PIE 미실행, 실행 핸들 없음.
- 남음: 실제 AnimBP 상태·2인 PIE·LOD/성능. 너구리 이동 영상/손전등도 미완료.
  임포트만으로 최종 완료 처리하지 않는다. 다음 제작: 거위 전용 모델/리그/울음·수면 포함 클립.
- 사용자 요청으로 전체 맵 배치·조립 제외. 필수 제작 45개, 별도 맵 작업 참고 17개.
  catalog 62행은 보존하고 필수 완료 0개를 유지한다.
