# 024 — 농부 A 몸/팔과 첫 UE 호환 검수

[제작 카드](../character/farmer_a.md), [실제 캐릭터 행](../evidence/024-character-contract.json).
신규 작업복/장갑/장화/얼굴/모자를 제작했다. 기존 Epic 표면 복제 없이 뼈와 기존 로코모션만 재사용했다.
원본 `ArtSource/character/farmer_a/farmer_a.blend`, 몸4100tris/2148정점/3재질,
팔1496tris/784정점/2재질. 각각 FBX/UV0 unwrap/UV1 palette/최대2가중치.

- 실제 Manny89뼈를 UE에서 조회했다. Blender88bone+root 오브젝트로 들어오는 구조와 원래 계층을 보존.
  [m 내보내기 실패](../evidence/024-rig-roundtrip.json): root scale100.
  [cm 복사본 왕복](../evidence/024-rig-roundtrip-cm.json):89뼈·부모·레스트 위치/회전/배율1 일치.
  원본 m 단위는 그대로 유지하며 내보내기 전용 복사본만 cm 단위다.
- [최종 임포트](../evidence/024-farmer-imports.json): 기존 SK_Mannequin 참조 포즈 해시 전후 일치.
  치수 오차<0.00002cm, 최대 참조 위치 오차0.000222cm/회전0.00954도/배율 오차0.00000656.
  새 메시만 저장했고 기존 Skeleton·BP·데이터를 덮어쓰지 않았다.
- [Walk 포즈 비교](../evidence/024-walk-pose-samples.json):1.5초 기존 Walk의7시점에서 원본/몸/팔89뼈 평가,
  위치 오차<0.002554cm. Blender로 가져온 두 포즈는 root 이동을 빼고 시각 검수했다.
  이것은 기존 로코모션 재사용 검수이며 신규 Carry/Use/피격 클립을 만든 것으로 세지 않는다.
- [실제 pawn PIE](../evidence/024-farmer-pie.json): CL9 pawn의 몸/팔을 임시 교체,
  ABP_Unarmed/ABP_FP_Copy 인스턴스 유지와 실제 AddMovementInput 이동/관절 갱신 확인.
  메시는 데이터 행이 아닌 PIE 인스턴스에만 적용했다. 1인칭 그립/카메라·슬롯·2인 통과 아님.
- [실제 조명 화면의 문제](../evidence/024-farmer-lit.png): 장화/장갑이 하얗게 나왔다.
  FBX에18색이 있고 UE 재내보내기에도 색이 남았지만 실제 shading에는 반영되지 않았다.
  Interchange 대신 명시한 legacy FBX 옵션으로 재임포트해도 이 현상은 남았다.
  엔진 원인으로 단정하지 않고 팔레트 텍스처로 해결했다. 다른 VC 자산에도 실제 색 검수가 필요하다.
- 공유18색256×8 PNG/UV1/nearest/no-mips/sRGB 팔레트로 옷·세부 재질을 변경.
  [최종 실제 UE 화면](../evidence/024-farmer-palette.png)에서 짙은 장화/갈색 장갑·벨트가 복원됐다.
  [캡처 기록](../evidence/024-farmer-palette-capture.json). 최종 Blender 중립·야간·손전등도 다시 저장했다.
  피부는 상수, 작업복은 palette×TintColor. UV0와 원래 vertex colour는 편집용으로 남겼다.
- 새 팔레트 후 변경 범위는 UV1/재질·노멀 임포트이며 기하/가중치/리그는 그대로다.
  최종 원본/FBX/UE 해시와 참조 포즈를 확인했다. 기존 이동 검수는 같은 변형/충돌 구조에 해당한다.
- 첫 SceneCapture는 조명이 없어 검은 화면이었다. 다음 검수에만 방향광2개를 추가했다.
  한 번의 정지 캡처 대신2초 동안 렌더 후 PNG를 저장했다. 실제 게임 시점의 검수와 구분한다.
- MaterialExpression 속성은 set_editor_property를 사용한다. SkeletalMaterial은 배열의 struct 복사본이므로
  변경한 슬롯을 인덱스에 다시 넣고 materials 배열을 설정해야 한다. 이 두 준비 오류를 수정했다.
- [정리](../evidence/024-farmer-fixtures.json): 바닥/캡처/조명2개 총4액터 제거, 원래29액터 보존,
  QA 맵만 저장/Lvl_Flat 복귀/PIE 종료. Interchange FBX cvar는 원래1로 복구.
