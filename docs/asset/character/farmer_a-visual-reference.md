범위: 다음 외형 수정의 시각 기준. 현재 모델·리그·UE 에셋을 수정하거나 기존 v3 채택 이력을 취소한 기록이 아니다.

## 참고 이미지의 용도

문장만 읽고 모델링하지 않는다. 아래 원본을 실제로 열고 대상 부분을 확인한다.
레퍼런스는 한 캐릭터의 정투상 설계도가 아니므로 장면 사이의 차이를 임의로 합쳐 확정하지 않는다.

| 원본 | 맞춰야 할 부분 | 이 그림으로 확정할 수 없는 부분 |
|---|---|---|
| [R1 달걀 회수 장면](../../../output/concepts/2026-10-10-local-game-loop-45s-v1/03-eggraid-reference.png) | 중앙 연두색 요리사의 둥근 실루엣, 얼굴과 앞치마의 배치, 짧은 팔다리, 큰 장갑, 작은 신발, 재료를 안는 자세 | 정확한 정면·측면 치수, 목의 구조, 손가락 수, 메시 분리와 리그 구조 |
| [R2 전신 전투 장면](../../../output/concepts/2026-10-10-combat-mockup-v1/combat-scene-mockup.png) | 전신의 옆 윤곽, 몸 옆에서 나와 앞으로 뻗는 팔, 통통한 손, 허리에 묶어 늘어지는 앞치마, 짧은 보폭 | 정확한 해부 구조, 물리 크기, 모자가 모든 캐릭터에 필수인지 여부 |
| [R3 1인칭 전투 장면](../../../output/concepts/2026-10-10-combat-mockup-v1/combat-scene-mockup-fps.png) | 전경의 노란 장갑·흰 커프·연두색 소매. 손등과 손가락 연결, 손목 전환, 소품을 감싸 쥔 형태 | 양손의 정확한 실측 비율, 원본 카메라 FOV, 가려진 손바닥·팔꿈치 토폴로지 |

**R1·R2는 전신 형태 기준, R3는 1인칭 손·팔 형태 기준이다.** 단순한 색·분위기 참고로 격하하지 않는다.
배경의 조명은 보조 분위기 참고다. 노란 조명색·그림자를 Base Color나 면별 얼룩으로 굽지 않는다.
몬스터용 양 레퍼런스는 일반적인 단순화 참고이며, 플레이어 손의 형태를 대신하지 않는다.

## 반드시 대조할 형태

| 부위 | 이미지에서 확인되는 기준 | 피해야 할 대체 해석 |
|---|---|---|
| 전신 | 둥근 상부에서 볼록한 아래 몸까지 이어지는 짧고 통통한 인상. 발과 손이 몸 밖에서 독립적으로 읽힘 | 큰 구 하나를 만들고 작은 부품만 붙인 뒤 색이 비슷하므로 완료 처리 |
| 얼굴 영역 | 윗부분에 모인 흰 눈과 검은 동공, 작은 입. 둥근 바탕 표면과 자연스럽게 이어짐 | 눈이 긴 원통처럼 앞으로 튀어나오거나 얼굴을 별도 가면처럼 붙임 |
| 머리·몸 관계 | R1·R2에는 뚜렷하게 노출된 목이 보이지 않음. 앞치마 위의 얼굴 영역과 아래 몸 영역은 구별됨 | '단일 반죽 생물' 또는 '분리된 큰 머리'를 이미지로 증명된 설정으로 단정 |
| 장갑 | 넓고 도톰한 손바닥·손등, 둥근 손끝, 손바닥에서 이어져 나오는 손가락, 옆으로 벌어진 엄지 | 손끝 구슬을 독립적으로 나열하거나 원통 손가락을 손등에 꽂은 외관 |
| 쥐는 손 | 엄지와 나머지 손가락이 소품의 양쪽을 감싸고 손바닥이 손잡이에 접근함 | 소품이 손바닥에서 떠 있거나 손가락이 핸들을 관통해도 색만 맞춰 통과 |
| 소매·커프 | 팔은 부피 있는 천의 인상, 흰 커프는 손목 둘레의 띠, 소매→커프→장갑이 자연스럽게 이어짐 | 속 빈 딱딱한 파이프 소매, 지나치게 큰 원판 커프, 분리된 손목 |
| 앞치마 | 허리에서 묶이고 몸 앞에 걸쳐 내려오는 얇은 천. 옆단·밑단·뒤 매듭이 역할을 구분함 | 몸 아래 절반 전체를 두꺼운 통이나 갑옷으로 감쌈 |
| 발 | 짧은 다리 아래 붙은 작은 짙은 신발, 바닥에 닿는 밑창과 앞으로 향하는 발끝 | 양끝이 같은 다면체 공 두 개, 떠 있는 신발, 과도하게 긴 성인형 다리 |
| 표면 | 둥근 외곽선 안에 절제된 넓은 면이 보임. 장갑·소매는 부드러운 볼륨이 먼저 읽힘 | 모든 면을 잘게 쪼개 색을 달리하거나, 반대로 모든 부위를 찰흙처럼 과도하게 매끈하게 만듦 |

'말랑한 장난감 느낌'은 볼륨과 윤곽에 대한 해석이다. 고무 광택·물리적 변형·고밀도 메시를 자동 요구하지 않는다.
소품에 닿는 손의 연속성은 시각 기준이며, 단일 메시인지 여러 메시인지는 결과를 보고 정할 구현 선택이다.
손가락 수와 숨은 신체 구조는 별도 제안에 기록한다. 그림에 가려진 부분을 확정 사실로 적지 않는다.

## 현재 산출물과의 차이 — 정적 이미지 검토

2026-10-11에 [전신 모아보기](../../../ArtSource/character/farmer_a/blockout/preview/body_contact.png)와
[팔 모아보기](../../../ArtSource/character/farmer_a/blockout/preview/fp_contact.png)를 열어 R1~R3와 비교했다.
이 경로는 제작 도구가 갱신하는 현재 미리보기이며 고정된 버전 증거가 아니다.

- 전신은 옆으로 넓어진 낮은 몸과 두꺼운 하반부 앞치마 때문에 R1·R2의 천과 몸 구분이 약하다.
  몸을 낮고 넓게 만든 것은 기존 v3의 변경 이력이다. 이 검토만으로 그 선택을 취소하지 않는다.
- 손가락의 둥근 끝 파츠가 따로 붙어 보이고, 손등에서 손가락으로 이어지는 큰 볼륨이 부족하다.
- 소매는 긴 다각형 관처럼, 커프는 딱딱한 띠처럼 보인다. R3의 도톰하고 부드러운 전환과 차이가 있다.
- 앞치마 밑단과 옆단, 작은 신발의 발끝 형태를 추가로 대조해야 한다.

이는 실제 파일을 새로 렌더하거나 리그를 실행한 결과가 아니다. 저장된 렌더의 시각 비교 결과다.
기존 제작 이력의 '렌더 확인/메시 검사/걷기 시험 완료'와 '컨셉 일치 확인'은 서로 다른 판정이다.

## 다음 수정의 검수 순서

1. R1~R3를 실제로 연다. 어떤 이미지의 어느 캐릭터·부위를 맞추는지 작업 기록 첫 줄에 적는다.
2. 기존 v3 원본·걷기 시험을 보존하고 별도 후보에서 작업한다. 게임 카메라·캡슐은 임의 변경하지 않는다.
3. 먼저 1인칭 손 한 쌍의 빈손·프라이팬 그립을 비교한다. 손바닥, 엄지, 손가락 연결과 소매 전환을 해결한다.
4. 전신은 R1 중앙 캐릭터와 비슷한 3/4 시점으로 비교한다. 정면·측면은 숨은 부분의 제안 검수용이다.
5. '레퍼런스 대상 부분 / 실제 모델 렌더 / 남은 차이'를 나란히 보여준다. 같은 화면상 높이로 맞추되 원근 차이를 적는다.
6. 전체 화면에서 실루엣, 확대 화면에서 손·앞치마, 중립광에서 표면을 확인한 뒤 게임 조명을 비교한다.
7. 완료 기록을 '생성됨 / 기술 검사됨 / 컨셉과 대조함 / 외형 채택됨 / 게임 연결됨'으로 분리한다.

대조표 각 행에는 일치·차이 있음·이미지로 판단 불가 중 하나와 렌더 경로를 적는다.
모든 행을 일치라고 쓸 필요는 없다. 남은 차이를 감춘 채 '참고 이미지에 맞춤'이라고 보고하지 않는다.
카메라 구도 때문에 안 보이는 부분은 검수 완료로 처리하지 않는다.

## 문서의 우선순위와 범위

- 이 문서는 이미지 대조 방법과 시각 제약을 보완한다. 새 외형을 사용자가 채택했다는 기록이 아니다.
- [제작 브리프](farmer_a-model-brief.md)의 v1·v2·v3 결과는 당시 작업 이력으로 보존한다.
  특히 '단일 달걀형'·'낮고 넓은 반죽'은 각 후보의 해석/수정 결과이며 원본 이미지 자체의 설명이 아니다.
- 최신 사용자 외형 선택과 이미지가 충돌하면 차이를 명시한다. 사용자 선택을 몰래 취소하거나 이미지를 그 선택에 맞춰 해석하지 않는다.
- 이 기준은 farmer_a용이다. 폐기된 몬스터 시안을 캐릭터나 몬스터 제작 기준으로 되살리지 않는다.
