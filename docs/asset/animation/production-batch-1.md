## 3. 지금 당장 막히는 것

- **컨셉 이미지가 없다.** 신규 셋(토끼·쥐·빈 돼지)과 재제작 둘(돼지·양)은 컨셉 승인이 첫 관문이다. 이미지는 ChatGPT(사용자가 2026-10-13에 정한 길)나 Tripo 이미지 생성(무료 할당, [tools/tripo.md](C:\Work\CL9\docs\asset\tools\tripo.md))으로 만든다. 입력 조건: 단일 오브젝트, 3/4 정면, 중앙, 균일한 짙은 회색 배경, 바닥면·그림자·글자 없음. 종마다 평상시·정체 순간 한 쌍, 후보 3~4개.
- **승인 대기 중인 것 여섯**: 귀여움 1단계 시안 넷(거위·돼지·너구리·양 v2), 소 돌진 공격 영상 v06, 닭 괴물 공격 영상 v06. 이것이 풀려야 1-3·1-4·0-b가 간다.
- **기술 검토 전인 것**: 쥐 떼를 그리는 방식, 피해 0 타격이 넘어짐을 내나, 벽 구멍 0~40cm(토끼 키 90cm는 구멍으로 못 나온다 — 통합 4의 B83: 토끼를 판 중간 등장에서 뺀다).
