# Lethal Company · R.E.P.O.를 CL9 제작 기준으로 옮기기

2026-09-10 사용자 지정: **두 게임의 방식과 분위기를 참고한다.**
구조 근거는 저장소의 [참고 분석](../reference/README.md)이다. 아래의 아트 해석과
샘플 지시는 CL9용 제작 방향이며, 원작의 정확한 폴리곤 수·텍스처 크기·조명 설정을 뜻하지 않는다.

## 분위기에서 가져올 것 — CL9 아트 해석

**리썰에서 참고하는 긴장과 불완전한 시야 + R.E.P.O.에서 참고하는 과장된 형태와 운반 중 사고**를
양계장의 목재·철망·볏짚·동물에 적용한다. 목표는 어둡고 우스꽝스러운 협동 원정이다.

- 배경은 넓은 색면과 제한된 세부 묘사로 만든다. 작은 흠집보다 문틀·통로·방의 실루엣이 먼저 보이게 한다.
- 어둠은 사물 일부를 숨기고, 손전등은 발견할 정보를 제한적으로 드러낸다. 모든 물체 가장자리를 빛내지 않는다.
- 위협은 알아볼 수 있는 체형과 큰 예고 동작으로 만든다. 닭의 긴장/추격/허둥거림이 한눈에 구분되어야 한다.
- 물건은 무게와 깨질 것 같은 인상을 형태로 전달한다. 둥근 계란과 걸리기 쉬운 수레 손잡이 등이 사례다.
- 동료는 단순한 몸과 뚜렷한 색 구역으로 읽히게 하고, 짐을 든 자세·넘어짐에서 웃음이 나오게 한다.
- 같은 벽을 반복해도 큰 특징 소품과 방의 용도가 길 기억을 돕게 한다. 모든 방을 잡동사니로 가득 채우지 않는다.

로우폴리는 실루엣을 의도적으로 정리하는 방향으로 사용한다. 모든 면을 Flat Shading하거나
텍스처 해상도를 일괄 낮추는 규칙은 아니다. 픽셀화·디더링·화면 노이즈 같은 후처리는
Blender 메시 규격에 넣지 않고 UE에서 별도 비교할 시각 효과 후보로 둔다.
원작의 외형 자산을 가져오기보다 CL9의 동물·요리·푸드트럭 소재로 구현한다.
