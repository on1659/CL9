# goal: screen-debugger

## One-line Goal
An in-game debugger panel (first tab: "Screen") that tunes every screen-look value live — retro effects we implement ourselves (pixelization, color reduction, palette, dithering), color grading, fog and lighting-phase values — and writes them back to the look table.

## Background / Motivation
2026-10-21 user: "디버거 패널 만들자 — 렌더링·몬스터 등 테스트용 치트가 있는 디버거 툴. 일단 포스트프로세싱 먼저, 노이즈·안개 등 다 세팅할 수 있게. 라이브러리가 있으면 쓰고 없으면 만들어."
Search result:
- UI library: Epic's **SlateIM** (engine plugin `Engine/Plugins/Experimental/SlateIM`, immediate-mode Slate "intended for building debugging tools") — sliders, spin boxes, combos, tabs, viewport roots. Used instead of hand-built UMG.
- Screen-effect packs on Fab are paid (Film and VHS Filters, VHS Pro, IMPERFECTER). The free pack that fits (VenediktVad "UE5 Pixelization/Dithering PostProcess", itch.io) is not imported; per the user we **re-implement its techniques** ourselves: pixelization, reduced palette, custom palette, dithering, selectable dither patterns, partial pixelization.

## In-scope
1. Look table (`UCL9LookDef`) new values
   - Retro (Screen): `PixelSize`, `PixelateFromDepth`, `ColorSteps`, `DitherPattern`, `DitherStrength`, `Palette`, `PaletteMix` (existing: `MaxResolution`, `AntiAliasing`, `PosterizeBands`, `PosterizeMix`, `Grain`).
   - Grade: `Saturation`, `Contrast`, `Gamma`, `Gain`, `Temperature`, `Tint`, `ShadowTint`, `HighlightTint`, `Vignette`, `Bloom`, `ChromaticAberration`, `Sharpen`, `MotionBlur` — defaults equal engine defaults (untouched table = unchanged screen).
   - Fog shape: `FogHeightFalloff`, `FogStartDistance`, `FogMaxOpacity`, `VolumetricFog`, `VolumetricFogExtinction`, `VolumetricFogDistance` — negative = keep the level's value.
2. Retro post-process material `/Game/Effects/M_CL9_PP_Retro` (After Tonemapping, one Custom HLSL node) built by `Tools/Unreal/create_retro_material.py`:
   pixelize (cell snap, optional depth threshold) → existing luminance posterize → per-channel color steps with ordered/noise dither → nearest-palette mapping (palette = 1×N strip texture, N ≤ 64) mixed by `PaletteMix`.
   Dither patterns: 0 none, 1 Bayer 2×2, 2 Bayer 4×4, 3 Bayer 8×8, 4 white noise.
   Starter palettes (`/Game/Effects/Palettes/T_Pal_*`) generated by the same script.
3. `UCL9LookModifier` feeds the new parameters; grade always applies, retro only with `bRetroLook`.
4. `ACL9NightLighting` applies fog shape when the look table revision changes.
5. Debugger panel (`FCL9ScreenDebugger`, SlateIM viewport root) drawn while the existing Tab debug screen is open — right side of the viewport. Sections: Retro / Grade / Lighting phase (current site profile; phase picker Lobby·Night·Blackout, default = current) / Fog shape. Buttons: revert to values at open, save table (editor only).
6. Labels go through the string table (`Debug.Screen.*`, ko only).

### Follow-up (2026-10-21, user request)
7. The monster spawn panel moves into the same SlateIM window as a top tab: **[Screen] [Monster spawn]**. Spawn count is a 1–20 spin box; monster buttons are two per row, equal width.
8. The Screen tab splits into sub-tabs **[Retro] [Grade] [Lighting] [Fog shape]**. Every row starts with the same 150px label column.
9. The panel height stretches to the viewport (16px margins); only the inner list scrolls when it overflows.
10. Opening the panel does **not** stop movement: it is no longer a UI-manager Screen, so `IMC_Gameplay` stays active. `ACL9PlayerController::SetDebugPanelOpen` only toggles the cursor (`GameAndUI` ↔ `GameOnly`). The old UMG `WBP_DebugPanel` is no longer opened by Tab.

## Out-of-scope
- Other cheat tabs beyond monster spawn.
- Palette file importers (.ase/.gpl …) and LUT generation from the free pack.
- Lamp kinds / surface families in the panel.

## Acceptance Criteria
- [ ] Editor build (`CL9Editor`) succeeds with SlateIM enabled.
- [ ] Untouched look table renders the same as before (grade defaults = engine defaults, fog shape = level values).
- [ ] In PIE, Tab opens the panel; dragging a slider changes the screen the same frame (pixel size, steps, dither, palette mix, saturation, fog density).
- [ ] Revert restores the values captured when the panel opened; Save writes `LookTable` (editor).
- [ ] Two PIE clients in one process do not crash (unique root name per controller).
- [ ] Shipping: panel code compiled out.

- Rendering stays local/presentational — no gameplay judgement reads these values.
- `bRetroLook` off = no retro pass (grade still applies).
