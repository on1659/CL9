# 설정 시스템 (로컬 옵션)

> 각 플레이어의 머신에 저장되는 개인 설정. **판 세이브([save.md](save.md))와 완전히 분리** —
> 설정은 로컬, 진행은 호스트의 것이다.

## 원칙

- **게임플레이 값을 노출하지 않는다.** 난이도·밸런스·시야 이득이 되는 옵션 금지 —
  난이도는 일자 곡선이 만들고, 어둠은 게임이다.
- 설정 UI는 `WBP_Main` 하위 화면 ([ui_system.md](ui_system.md)) — 타이틀·일시정지 양쪽에서 진입.

## 항목

### 오디오

사운드 믹스 클래스별 볼륨 슬라이더 — [sound.md](sound.md)의 Master Mix 훅을 그대로 쓴다:

| 슬라이더 | 대상 클래스 | 기본 |
|---|---|---|
| 전체 | Master | 1.0 |
| 효과음 | Effects (SFX) | 0.8 |
| UI | UI | 1.0 |
| 배경음 | Ambience | 0.5 |
| 음악 | Music | 0.7 |
| 음성 | VO | 1.0 |

### 그래픽

- 해상도·창 모드·수직동기·품질 프리셋 — `UGameUserSettings` 표준 항목 그대로.
- 감마/밝기 슬라이더 범위는 조명 렌더 세팅과 함께 정한다 ([light.md](light.md)) — 값 미결.

### 입력

- 키 리바인딩 — Enhanced Input User Settings ([input.md](input.md)). Esc는 제외.
- 마우스 감도 (Look 배율), Y축 반전.

### 접근성

- 자막 — 모든 오디오 신호(반응 음성·경보 울음 포함)에 텍스트 대안 (ui.md 접근성).
- UI 스케일.

### 언어

- `FText` 현지화 기반. 시작은 한국어 하나 — 언어 선택은 두 번째 언어가 생길 때 노출 (미결).

## 저장 구조

| 무엇 | 어디 |
|---|---|
| 그래픽·오디오·접근성 | `UCL9GameUserSettings : UGameUserSettings` (엔진 표준 ini) |
| 키 리바인딩·감도 | Enhanced Input User Settings (자체 저장) |
| 판 진행 | ❌ 여기 아님 — [save.md](save.md) |

- 적용은 즉시(슬라이더 드래그 중 미리듣기/미리보기), 저장은 화면 닫을 때.
- 설정은 복제되지 않는다 — 전부 로컬 전용.
