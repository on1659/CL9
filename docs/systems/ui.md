# UI/UX 설계 (HUD 레이아웃)

> 화면에 무엇을 띄우고 무엇을 띄우지 않는가. 미니맵 표시는 전역 금지가 아니라
> **개체별 값(`bShowOnMinimap`)**으로 제어하고, 스태미나 바 없음은 rules.md의 흔들림 규칙에서 온다.

## HUD 방침

- **미니맵 표시는 개체별 값이다** — 몬스터·아이템의 `bShowOnMinimap`(기본 false)을 미니맵
  시스템이 읽는다. 전역 금지 원칙이 아니라 표에서 켜고 끈다
- 스태미나 바 없음 — 화면 흔들림 진폭으로 읽힌다 (plan/data/rules.md)
- 능력 바(회피/공격/아이템) 없음 — 그런 조작이 없다
- 라운드 목표금액·달성률 표시 없음 — 정산은 이틀 주기 기간 수입이다
- HP 표시는 **하트 초안** (2026-09-05): 좌상단에 ♥ × HP 개수 (10 초과 시 숫자) — 확정은
  플레이해보고. 바·퍼센트는 쓰지 않는 방향 (관리 자원화 방지 — 흔들림 규칙과 같은 결)

## 게임 중 HUD

```
┌─────────────────────────────────────────────────┐
│ [상단] N일차 · 밤 시계 (NightLength 잔여)        │
│                                                 │
│ [좌상단] 이더 (판 공유 자금)                     │
│                                                 │
│              [게임 플레이 화면 (3D)]             │
│                                                 │
│ [좌하단] 진행 중 주문 (남은 재료 · 마감 일수)    │
│ [하단 중앙] 상호작용 프롬프트 · 던지기 차징      │
│ [우하단] 짐 슬롯 (손 · 품)                       │
└─────────────────────────────────────────────────┘
```

| 요소 | 내용 | 근거 |
|---|---|---|
| 밤 시계 | `NightLength` 잔여 — 만료가 실패라 보여야 한다 | rules.md |
| 이더 | `GameState.SharedMoney` (판 공유) | economy.md |
| 짐 슬롯 | 손에 든 것 + 품(Pocketable) | inventory.md |
| 주문 | 선택한 주문의 남은 재료·마감 | order.md |
| 상호작용 | 줍기·놓기·반납 프롬프트, 던지기 차징 게이지 | raiding.md |

- 던지기 차징은 조작 피드백이라 게이지가 허용된다 — 스태미나 같은 "관리 자원"이 아니다.
- 미니맵은 초기 구현에서 생략. 넣을 때 무엇이 그려지는지는 개체별 `bShowOnMinimap` 값이 정한다.

## 화면 전환 — WBP_Main 하위

뷰포트에 붙는 위젯은 `WBP_Main` 하나이고, 전면 화면은 UIManager가 UI 표를 읽어 Screen
레이어에 배타적으로 연다 ([ui_system.md](ui_system.md) — 2026-09-05 구조 결정).

### 로비 (정차)

```
┌─────────────────────────────┐
│  N일차 · 누적 이더           │
│  플레이어 슬롯 0~3 (색 표시) │
│  캐릭터 선택                 │
│  주문서 선택 (N개 중 M개)    │
│  목적지 선택                 │
│  [밤 시작] (호스트)          │
└─────────────────────────────┘
```

### 새벽 (밤 종료)

```
┌─────────────────────────────┐
│  N일차 결과                  │
│  회수한 것 · 납품한 주문     │
│  이번 기간 수입 / 정산 목표   │
│  (정산일이면 판정 결과)      │
│  [다음 날] (호스트)          │
└─────────────────────────────┘
```

### 관전 (사망 시)

죽으면 `SpectateDelay` 뒤 동료 시점 관전으로 넘어간다. 부활 UI는 없다 — 회복 채널은
트럭 패드뿐이다.

### 일시정지

[계속] [설정] [로비로 나가기] [게임 종료] — 멀티에서는 게임을 멈추지 않는다.

## UI 애니메이션

- 화면 전환 0.3초 페이드, 패널 0.2초 슬라이드
- 중요 알림 번쩍임은 밤 만료 임박에만 제한적으로

## 접근성

- 글꼴 최소 16pt, 명확한 색 대비
- 슬롯 색(`TintColor`)은 채도가 충분해야 한다 — 어둠 속 유일한 식별 수단
- 모든 오디오 신호에 텍스트 대안 (자막 옵션)
