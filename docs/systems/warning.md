# 경고·정보 전달 시스템

> 플레이어가 위험을 어떻게 아는가. 현재 설계는 위협 정보를 UI 텍스트보다 **월드 연출**로
> 전달한다 — "무엇을 하려는지 읽을 수 있어야 대응이 실력이 된다" (plan/overview.md 재미 요소).

## 정리된 경고 (이전 판 이력)

이전 판의 아래 경고들은 현재 설계 방향에 맞지 않아 정리했다 (2026-08-31, decisions.md) —
금지 목록이 아니라 이력이다:

- ❌ **몬스터 접근 경고** ("몬스터 접근 중! 거리 50m", 방향 화살표) — 현재 설계는 위협을
  월드에서 읽게 한다
- ❌ **팀원 피해 텍스트 팝업 + 위치 핑** — 동료 상황은 **반응 음성(`VoiceSet`)**이 어둠 속에서
  귀로 알리는 채널이다 ([../plan/data/character.md](../plan/data/character.md))
- ❌ **HP % 경고** — HP는 3이다. % 문턱 개념이 없다
- ❌ **인벤토리 가득/무게 경고** — 슬롯 인벤토리가 없다 ([inventory.md](inventory.md))
- ❌ **판매 목표 경고** — 라운드별 목표금액이 없다. 정산은 이틀 주기 기간 수입이다

## 정보가 전달되는 채널

### 월드 연출 (판정과 분리된 렌더 전용)

| 신호 | 무엇을 알리나 | 값 |
|---|---|---|
| `WakeTelegraph` 퍼덕임·울음 | 몬스터가 깨어난다 (전 플레이어에게 보인다) | 0.8초 |
| 연기 기둥 (`BurnWarnTime`) | 요리가 타기 직전이다 | 6초 전 |
| 거위 `AlertWindup` 예비동작 | 경보 직전 | 0.55초 |
| 조명 깜빡임 (연출 미정) | 정전 접근 | 미정 |

### 소리

- 반응 음성(`VoiceSet`): 잡힘·넘어짐·탈진 — 동료 상황을 귀로 알린다
- 발소리(`FootstepSet`), 몬스터 울음, 죽는 소리(사살 경보의 표현)
- 호출 규칙은 conventions.md § 9 — 표현 계층에서만, Multicast 동기화

### 몸 감각

- **스태미나: 화면 흔들림 진폭으로만.** 바·게이지 없음 (현재 설계 — 근거는 [../plan/data/rules.md](../plan/data/rules.md))
- **피격: 비틀거림(`HurtStun` 0.35초)·넘어짐 + 카메라 셰이크(셰이크 표 `Hurt` 행) + 빨간 화면 비네트(`HurtVignetteTime` 동안 옅어진다)
  + 몸이 빨개짐(`HurtFlashTime`, 남의 화면에서도 보인다)** — 2026-09-15 구현
  ([character.md](character.md) 맞는 느낌 절). 때린 쪽도 마찬가지로 몬스터가 빨개지고 카메라가 한 번 튕긴다.

### 허용되는 UI 표시

위협이 아닌 상태 정보는 HUD에 표시할 수 있다 ([ui.md](ui.md)):

- 밤 시계 (`NightLength` 잔여) — 만료가 실패이므로 보여야 한다
- 진행 중 주문·마감 일수
- 손·품에 든 것 (짐 슬롯)

## 구현

- 월드 연출은 해당 액터의 Multicast/OnRep 표현 코드에서 (판정과 분리 — 렌더 전용)
- 반응 음성은 캐릭터 이벤트(잡힘·넘어짐·탈진)에 물린다 — 몬스터 청각 판정에는 안 들어간다
- 빈도 제한: 같은 음성·연출을 2초 안에 반복하지 않는다
